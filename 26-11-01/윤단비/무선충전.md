# SWEA 5644. 무선 충전

## 1. 문제 접근 방식
- 사용자 A와 B의 이동 경로를 각각 시뮬레이션한다.
- 매 시간마다 두 사용자의 현재 위치에서 충전 가능한 BC를 탐색한다.
- 두 사용자가 선택할 수 있는 충전기 조합을 비교하여 최대 충전량을 구한다.
- 시작 위치에서도 충전이 가능하므로 이동 전 초기 위치부터 계산한다.

## 2. 핵심 아이디어
- **시뮬레이션**: 이동 방향에 따라 사용자들의 좌표를 갱신한다.
- **조합 탐색**: 두 사용자가 선택할 수 있는 BC 조합을 비교한다.
- **충전량 최댓값**: 같은 BC를 선택하는 경우에도 충전량이 중복 계산되지 않도록 처리한다.

## 3. 시간복잡도
- 이동 횟수: M
- 충전기의 개수: A
- 매 시간마다 두 사용자의 충전기 조합을 확인한다.

전체 시간복잡도: O(M × A²)

## 4. 풀이하면서 실수했던 부분
- 초기 위치에서의 충전량도 계산해야 한다는 점을 놓치기 쉬웠다.
