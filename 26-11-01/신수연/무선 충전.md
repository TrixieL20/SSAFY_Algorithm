# 접근 방법

- 두 사용자의 이동 경로를 따라 위치를 갱신하는 **시뮬레이션**과 충전기 선택 조합을 확인하는 **완전탐색**을 사용했다.
- 사용자 A는 `(1, 1)`, 사용자 B는 `(10, 10)`에서 시작하며, 이동 전인 **0초에도 충전**할 수 있으므로 0초부터 M초까지 탐색했다.
- 매 시각 두 사용자와 각 충전기 사이의 맨해튼 거리를 계산하여 접속 가능 여부를 확인했다.
- 두 사용자가 선택할 수 있는 충전기 조합을 모두 확인하여 해당 시각의 최대 충전량을 구했다.
- 각 시각에 구한 최대 충전량을 누적하여 정답을 계산했다.

<br>

# 핵심 아이디어

- **맨해튼 거리로 충전 범위 판별**
  - 사용자 위치가 `(x, y)`, 충전기 위치가 `(bc.x, bc.y)`일 때 거리는 다음과 같다.
  - `|x - bc.x| + |y - bc.y|`
  - 이 거리가 충전 범위 `c` 이하이면 해당 충전기에 접속할 수 있다.

- **개인의 최대 충전량보다 두 사용자의 합을 고려**
  - 두 사용자가 각각 성능이 가장 높은 충전기를 선택하면 같은 충전기에 접속하여 충전량을 나눠 받을 수 있다.
  - 따라서 모든 충전기 선택 조합을 확인하여 두 사용자의 충전량 합이 가장 큰 경우를 선택한다.
  - 예를 들어 성능이 100과 80인 충전기에 두 사용자 모두 접속할 수 있다면, 100인 충전기를 함께 사용하는 것보다 서로 다른 충전기를 선택하여 총 180을 얻는 것이 유리하다.

- **같은 충전기 사용 여부에 따른 계산**
  - 서로 다른 충전기에 접속하면 각 충전기의 성능을 더한다.
  - 같은 충전기에 두 사용자 모두 접속하면 충전 성능을 절반씩 나눠 받는다.
  - 선택한 충전기에 접속할 수 없는 사용자의 충전량은 0으로 처리한다.

- **매 시각의 최댓값을 독립적으로 계산**
  - 현재 선택한 충전기가 다음 시각의 이동이나 충전에 영향을 주지 않는다.
  - 따라서 매 시각 최대 충전량을 구해 누적하면 전체 최대 충전량을 얻을 수 있다.

<br>

# 시간복잡도

- `M`: 이동 시간, `A`: 충전기 개수
- 시간복잡도: **O((M + 1) × A²)**
  - 매 시각 접속 가능한 충전기를 확인하는 데 O(A)가 필요하다.
  - 두 사용자의 충전기 선택 조합을 확인하는 데 O(A²)가 필요하다.
  - 이를 0초부터 M초까지 총 M + 1번 반복한다.
- 공간복잡도: **O(M + A)**
  - 이동 정보를 저장하는 배열에 O(M)이 필요하다.
  - 충전기 정보와 접속 가능 여부 배열에 O(A)가 필요하다.
