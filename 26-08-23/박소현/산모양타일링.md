# 문제 접근 방식
- 경우의 수를 일일이 다 찾으면 무조건 시간 초과 날 것 같아서, 점화식을 찾으려고 했다.

# 핵심 아이디어
n - 1의 경우의 수를 오른쪽 아래 삼각형이 없는 경우(n 번째 삼각형에서 쓰고 있는 경우) a와 오른쪽 아래 삼각형으로 마름모를 만들고 있는 경우인 b로 나누어 구했다.

## 점화식
| 1 | n |
|-|-|
| a(1) = (3 or 2) | a(n) = a(n - 1) * (3 or 2) + b(n - 1) * (2 or 1) |
| b(1) = 1 | b(n) = a(n - 1) + b(n - 1) |
* (x or y)는 top의 유무에 따라 달라진다.

# 복잡도
## 시간 복잡도
O(N)
## 공간 복잡도
O(1)

# 풀이하면서 실수했던 부분
- 점화식을 못 찾겠어서, 타인의 도움을 받았다. 점화식을 만드는 연습을 좀 더 해야 할 것 같다.
