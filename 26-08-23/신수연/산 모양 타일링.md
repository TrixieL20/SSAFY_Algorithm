# 접근 방법
산 모양으로 배치된 삼각형 영역을 왼쪽부터 하나씩 타일링하면서, 현재 위치의 오른쪽 경계가 어떤 상태로 남아 있는지를 기준으로 DP를 구성한다.

현재 위치에서 다음 영역으로 넘어갈 때, 오른쪽 아래 삼각형이 이미 마름모에 포함되었는지 여부에 따라 이후에 타일을 배치할 수 있는 경우가 달라진다.

따라서 각 위치마다 2개의 상태를 관리한다.

dp[i][0] : i번째까지 타일링했을 때 오른쪽 아래 삼각형이 마름모에 포함된 상태
dp[i][1] : i번째까지 타일링했을 때 오른쪽 아래 삼각형이 남아 있는 상태


<br>

# 핵심 아이디어

- 초기 상태는 아직 아무 타일도 배치하지 않은 상태이므로 `dp[0][0] = 0;`, `dp[0][1] = 1;`로 설정한다.
- 이후 i = 1부터 n까지 순서대로 타일링한다.
  - dp[i][0]
    - 현재 오른쪽 아래 삼각형이 마름모에 포함되는 경우이다.
    - 이 상태는 이전 위치의 두 상태에서 모두 만들 수 있으므로 `dp[i][0] = dp[i - 1][0] + dp[i - 1][1];`이다.
  - tops[i - 1] == 0
    - 현재 위치에 위쪽 삼각형이 없는 경우이다.
    - 이때 dp[i][1]은 이전 상태에 따라 `dp[i][1] = dp[i - 1][0] + 2 * dp[i - 1][1];`로 계산한다.
    - dp[i - 1][0] 상태에서는 1가지, dp[i - 1][1] 상태에서는 2가지 방법으로 현재 상태를 만들 수 있다.
 - tops[i - 1] == 1
    - 현재 위치에 위쪽 삼각형이 존재하는 경우이다.
    - 위쪽 삼각형을 활용할 수 있기 때문에 tops[i - 1] == 0인 경우보다 타일링 방법이 증가한다.
    - 따라서 `dp[i][1] = 2 * dp[i - 1][0] + 3 * dp[i - 1][1];` 점화식을 사용한다.
    - dp[i - 1][0] 상태에서는 2가지, dp[i - 1][1] 상태에서는 3가지 방법으로 현재 상태를 만들 수 있다.


# 시간복잡도
i = 1부터 n까지 한 번씩 순회하므로 시간복잡도는 `O(n)`이다.
