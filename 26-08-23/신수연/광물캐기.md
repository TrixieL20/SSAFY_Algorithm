# 접근 방법
곡괭이의 종류에 따라 같은 광물을 캐더라도 피로도가 달라진다.

따라서 현재 위치에서 사용할 수 있는 곡괭이를 하나씩 선택해보고, 각각의 선택에 따른 피로도를 계산하여 모든 경우를 탐색하는 dfs(백트래킹) 방식으로 해결한다.

곡괭이 하나를 선택하면 최대 5개의 광물을 캐고, 그다음 남은 곡괭이 중 하나를 다시 선택하는 방식으로 탐색한다.

각 경우의 피로도를 누적하고, 모든 광물을 캤거나 곡괭이를 모두 사용한 경우 최솟값을 갱신한다.
<br>

# 핵심 아이디어

- 각 광물에 대해 곡괭이 종류별 피로도를 HashMap에 저장한다.
- dfs를 이용해 곡괭이를 선택한다.
  - 다이아 곡괭이를 하나 사용한 뒤 DFS를 호출하고, 탐색이 끝나면 다시 곡괭이를 복구한다.
  - 곡괭이의 개수를 직접 변경하면서 탐색하기 때문에 탐색이 끝난 후 원래 상태로 복구해야 한다.
  - 이 과정을 통해 현재 선택이 다른 탐색에 영향을 주지 않도록 한다.
  - 곡괭이 하나를 사용하면 최대 5개의 광물을 캘 수 있으므로 다음 dfs에서는 시작 인덱스를 5 증가시킨다.
  - 광물이 5개보다 적게 남은 경우에는 getFatigue()에서 실제 존재하는 광물까지만 계산한다.
- dfs는 `idx`가 `minerals.length`보다 크거나 같을 때, 또는 곡괭이를 모두 사용했을 때 `min`비교 후 리턴한다.

<br>

# 시간복잡도
각 테스트 케이스마다 X / 2번 반복하여 8을 추가하므로, `O(X)`

테스트 케이스가 T개라면 전체 시간복잡도는
`O(T × X)`
