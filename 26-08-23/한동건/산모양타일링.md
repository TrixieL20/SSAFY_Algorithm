# 접근 방법

- 왼쪽 삼각형부터 오른쪽으로 순회하며, 각 위치까지 도형을 채우는 경우의 수를 DP로 누적
- 매 위치마다 "오른쪽으로 아무것도 안 걸치고 딱 떨어지게 마무리된 상태(dp1)"와 "오른쪽 삼각형과 마름모를 만들 여지를 남긴 채 마무리된 상태(dp2)" 두 가지로 나눠서 관리
- 다음 칸으로 넘어갈 때 `tops[i]`(위에 삼각형이 붙어있는지 여부)에 따라 결합 가능한 경우의 수가 달라지므로, 그 값을 계수에 반영해서 전이

<br>

# 핵심 아이디어

- 이 문제는 도형 전체를 한 번에 세려 하면 경우의 수가 기하급수적으로 폭발하므로, "i번째까지 채운 상태"를 두 가지 상태로 압축한 게 관건
- dp1(깔끔히 끝남)에서 dp2(걸쳐서 끝남)로 넘어갈 때는 top 유무에 따라 `(1+tops[i])`, dp2에서 dp2로 이어질 때는 `(2+tops[i])`로 계수가 붙는데, 이건 top이 있을 때 도형 위쪽 삼각형과 결합하는 조합이 하나 더 생기기 때문
- top이 없는 상태(모든 tops=0)에서 점화식을 그대로 돌리면 순수 피보나치 수열이 나온다는 걸 확인 → 애초에 이 도형의 밑바탕이 피보나치형 타일링 문제였다는 걸 검증 삼아 확인함

<br>

# 시간복잡도

- N = n 
- DP 배열을 한 번씩만 순회하므로 O(N)
- N ≤ 100,000이라 O(N)이면 여유롭게 통과, 굳이 행렬 거듭제곱 등으로 최적화할 필요 없음
- 매 연산마다 mod 10007을 취해야 함 (안 하면 Python도 bignum 연산 때문에 시간초과)

<br>


# 어려웠던 점 / 배운점

처음엔 도형 전체 경우의 수를 완전탐색으로 세보려 했는데, n이 100,000까지 가는 문제라 애초에 불가능한 접근이었다. DP로 풀어야 한다는 건 알았지만 익숙하지 않은 유형이라 점화식을 스스로 세우는 데는 결국 AI의 도움을 받았다.

풀이 과정을 보고 나니 점화식 자체는 몇 줄 안 되고 이해도 어렵지 않았는데, 정작 그 점화식을 처음부터 스스로 도출하는 과정이 훨씬 어렵게 느껴졌다.
상태를 몇 개로 나눌지, 각 상태가 도형의 어떤 부분을 의미하는지를 끈질기게 손으로 따져보는 연습이 부족했던 것 같다. 
다음엔 답을 먼저 찾기보다 작은 케이스(n=1, n=2)부터 직접 세어보면서 점화식 후보를 스스로 추측해보는 습관을 들여야겠다.
