# 접근 방법
- queue를 이용해서 이동할 수 있는 경로들을 넣어두고 근처부터 탐색하는 BFS 사용

## 자료구조
- Queue<int[]> queue -> 이동할 수 있는 x, y 좌표 수집
- int[][] visited -> 이동 시 얼마나 시작점에서 이동했는지 기록

<br>

# 핵심 아이디어

* 큐를 이용해 근처에서부터 탐색해나감

<br>

# 시간복잡도

```
O(N×M)
```
- 세로 : N, 가로 : M
  <br>

# 배운 점
- Queue는 참조 타입(객체)을 저장하는 자료구조인데 int[]도 객체라서 Queue에 들어갈 수 있다는 것을 알게 되었다.
<br>

# 실수한 부분
- 의사코드를 작성할 때 갈 수 있는 길인지 체크하는 부분을 빼먹어서 제출하고 틀리고 깨달았다.
- 의사코드에는 똑바로 적었지만 코드에 cy, cx 기준으로 조건을 체크해야 하는데 x, y 기준으로 체크하는 실수를 했다.
