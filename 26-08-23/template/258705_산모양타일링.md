# 접근 방법

산 모양의 타일은 삼각형 형태로 이루어져 있는데 사각형으로 치환해 tops와 산 아래 부분을 치환할 수 있을 것 같았다.

`tops` 배열을 왜 따로 제공하는지부터 고민하다 산의 아래쪽을 tops와 나눠서 생각해 아래 부분만을 하나의 배열처럼 펼쳐서 생각할 수 있을 것 같았다.

그래서 산 아래 부분을 `2n + 1`개의 배열로 만들고 각 위치까지 타일을 채우는 경우의 수를 DP로 계산했다.

이때 현재 위치가 짝수 번째이고 해당 산에 `tops`가 존재하는 경우와 존재하지 않는 경우를 나누어 점화식을 구성했다.

- `tops`가 없는 경우에는 배열[idx - 2] + 배열[idx - 1]을 구한 후 10007로 나눈 나머지를 저장한다.
- `tops`가 있는 경우에는 위쪽 삼각형이 추가되면서 평행사변형 형태의 타일링 방법이 하나 더 생기므로 배열[idx - 2] * 2 + 배열[idx - 1]을 구한 후 10007로 나눈 나머지를 저장한다.
- 
처음에는 문제의 구조가 복잡해 보였지만 직접 하나씩 그려보면서 경우의 수가 이전 상태에만 의존한다는 것을 확인했고 결국 점화식을 구해 DP로 해결할 수 있었다.

<br>

## 자료구조

- `int[] lowerMountain`
  - 산 모양을 아래쪽 기준으로 펼쳤을 때, 각 위치까지 타일을 채우는 경우의 수를 저장하는 DP 배열
- `int[] tops`
  - 각 산의 위쪽에 삼각형이 존재하는지 여부를 저장

<br>

# 핵심 아이디어

현재 위치를 `i`라고 했을 때, 타일링 방법은 크게 이전 상태를 이어받는 경우와 두 칸 전의 상태에서 새로운 구조를 만드는 경우로 나눌 수 있다.

기본적으로는 다음과 같은 점화식을 사용한다.

```text
dp[i] = dp[i - 2] + dp[i - 1]
````

하지만 현재 위치가 산의 위쪽 삼각형과 연결되는 위치이고 해당 산에 추가 삼각형이 존재한다면 타일을 배치할 수 있는 방법이 하나 더 늘어난다.

따라서 `tops`가 존재하는 경우에는 아래의 점화식을 사용한다.

```text
dp[i] = dp[i - 2] + 2 * dp[i - 1]
```


* `tops`가 없는 경우
  → 이전 상태에서 이어지는 기본 경우의 수만 고려

* `tops`가 있는 경우
  → 위쪽에 추가된 삼각형으로 인해 평행사변형 형태의 배치가 가능해지므로 `dp[i - 1]`에서 만들 수 있는 경우가 하나 더 추가됨

최종적으로 `2n + 1`번째 위치까지의 경우의 수를 반환하면 된다.

<br>

# 시간복잡도

```text
O(n)
```

<br>

# 배운 점

* 처음에는 삼각형 구조 때문에 복잡하게 느껴졌지만 **경우의 수에 따른 삼각형을 직접 그리고 배열에 대입**해보면서 점화식을 훨씬 쉽게 찾을 수 있었다.
* `tops`가 왜 별도의 배열로 주어졌는지 고민하면서 특정 위치에서 경우의 수가 달라지는 조건이라는 것을 파악할 수 있었다.
