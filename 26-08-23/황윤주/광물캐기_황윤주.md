<br>

# 접근 방법
- 광물을 5개씩 묶어서 하나의 작업 단위로 생각하였다
- 좋은 곡괭이를 가장 피로도가 큰 묶음에 사용하는 것이 유리하므로 그리디 방식으로 접근
- 각 묶음의 가치를 계산한 뒤 내림차순 정렬하여 다이아 곡괭이 ->철 곡괭이 -> 돌 곡괭이 순으로 배정하였다


## 자료구조
- List<Group> : 5개 단위 광물 묶음 저장
- Group : diamond 개수, iron 개수, stone 개수 저장 

<br>

# 핵심 아이디어

1. 광물을 5개씩 그룹화
2. 돌 곡괭이 기준 피로도 계산 -> 피로도 높을수록 좋은 곡괭이랄 사용해야 하는 그룹
3. 가장 힘든 그룹부터 처리할 수 있도록 피로도 내림차순 정렬
4. 정렬 그룹 순서대로 좋은 곡괭이 배정 
<br>

# 시간복잡도

```
O(M log M)
```
- 생성된 광물 그룹 개수 : M
  <br>

# 배운 점
- 광물을 하나씩 보는 것이 아니라 5개 단위로 묶어서 생각하면 문제를 훨씬 단순하게 만들 수 있다는 점을 배웠다 
- 그룹 정렬 기준을 처음에는 다이아 개수만으로 설정하려고 했는데, 철과 돌도 고려해야 정확한 우선순위를 만들 수 있다는 점을 놓쳤다

  <br>

# 실수한 부분
- 처음에는 광물을 순서대로 탐색하면서 남아있는 가장 좋은 곡괭이를 사용하는 방식으로 접근하려 했다
- 하지만 이는 전체 최적해를 보장하지 못한다는 점을 깨달았다
