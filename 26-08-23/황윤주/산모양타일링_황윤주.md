# 접근 방법
- tops[i]의 값에 따라 각 열에서 만들 수 있는 타일링 방법의 수가 달라지기 때문에,이전 열의 결과를 이용해서 현재 열의 경우의 수를 계산하는 DP 방식으롲 접근
- 열의 상태를 dp[i][0] / dp[i][1] 두 가지로 나누어 관리
  - dp[i][0]
  i번째 열까지 타일을 채웠을 때 현재 열의 경계 부분이 특정 상태인 경우의 수
  - dp[i][1]
  i번째 열까지 타일을 채웠을 때 다른 경계 상태의 경우의 수

## 자료구조
- `long[][] dp` -> 각 열의 타일링 경우의 수를 저장
- `dp[i][0]`, `dp[i][1]` 두 가지 상태를 이용하여 이전 열에서 현재 열로 이어지는 경우의 수를 계산

<br>

# 핵심 아이디어

* 이전 열의 결과를 이용하여 현재 열의 타일링 경우의 수를 계산하는 DP
* `tops[i] == 0`인 경우
    - `dp[i][0] = dp[i-1][0] * 2 + dp[i-1][1]`
* `tops[i] == 1`인 경우
    - `dp[i][0] = dp[i-1][0] * 3 + dp[i-1][1] * 2`
* `dp[i][1]`은 `tops[i]`와 관계없이
    - `dp[i][1] = dp[i-1][0] + dp[i-1][1]`
* 마지막 열의 두 상태를 더하면 전체 타일링 경우의 수를 구할 수 있음
* 경우의 수가 커질 수 있기 때문에 매 계산마다 `10007`로 나눈 나머지를 저장

<br>

# 시간복잡도

```
O(N)
```

  <br>

# 배운 점
- 타일링 문제에서도 단순히 전체 경우의 수를 구하는 것이 아니라, 이전 상태에 따라 현재 상태가 어떻게 달라지는지 나누어 생각해야 한다는 것을 알게 되었다.
- DP에서 상태를 어떻게 정의하느냐에 따라 점화식을 쉽게 만들 수 있다는 것을 배웠다.
- `tops[i]`의 값에 따라 경우의 수가 달라지는 부분을 각각 점화식으로 표현하는 방법을 익혔다.
- 경우의 수를 저장할 때 값이 커질 수 있으므로 문제에서 주어진 `MOD`를 활용하여 계산하는 방법을 배웠다.


# 실수한 부분
- 처음에는 타일을 직접 배치하는 경우를 하나씩 생각하려고 해서 경우의 수가 복잡하게 느껴졌다.
- 그래서 GPT에게 아이디어 도움을 받아 dp와 점화식을 사용하는 아이디어를 얻었다 
- `tops[i]`가 `0`일 때와 `1`일 때의 경우의 수가 왜 다른지 상태를 나누어 생각하는 과정이 어려웠다.
- `dp[i][0]`과 `dp[i][1]`의 의미를 정확하게 정의하지 않으면 점화식을 이해하기 어려웠기 때문에, 각 상태가 어떤 모양으로 끝나는지를 기준으로 생각했다.
- 첫 번째 열은 이전 열의 값을 참조할 수 없기 때문에 별도로 초기화해야 한다는 점을 주의했다.
