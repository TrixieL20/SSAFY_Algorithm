## 1️⃣ 문제 접근 방식

#### 📌 사용 알고리즘 - 그리디 + 정렬

곡괭이 하나당 무조건 광물 5개를 캐므로 광물을 5개씩 묶고, 다이아가 많은 순 -> 철이 많은 순으로 정렬해 피로도가 높은 광물이 많은 순으로 다이아 -> 철 -> 돌곡괭이 소진하도록 했음

## 2️⃣ 핵심 아이디어

🌟 보유 곡괭이 개수 * 5와 광물 개수 비교해 더 작은 쪽을 구함 => 캘 수 있는 광물 어디까지인지 확인

🌟 광물을 5개씩 묶어 다이아 / 철 / 돌 개수 저장

🌟 다이아 많은 묶음 → 철 많은 묶음 순으로 정렬

🌟 다이아 → 철 → 돌 곡괭이 순서로 사용하면서 피로도 계산

---

✏️ 풀이 과정

1️⃣ 곡괭이 개수 × 5와 전체 광물 수 중 작은 값만큼만 확인

2️⃣ 광물을 5개씩 묶어 종류별 개수 저장

3️⃣ 다이아, 철이 많은 묶음부터 정렬

4️⃣ 좋은 곡괭이부터 순서대로 사용하면서 피로도를 누적

## 3️⃣ 시간복잡도

O(n log n)



## 4️⃣ 풀이하면서 실수했던 부분

처음에는 광물 개수가 곡괭이 개수 * 5보다 작은 경우를 생각 못해서 곡괭이 개수만큼 광물 확인하고 피로도 누적하는 로직 짰다가 array index가 벗어나 error 발생했다! 따라서 이후에 광물 개수와 곡괭이 개수 * 5를 비교해 작은 값을 취해 캘 수 있는 최대 광물 개수로 설정하도록 했다.
