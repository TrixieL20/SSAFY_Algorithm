# 접근 방법 / 핵심 아이디어

- **시뮬레이션 + 매 초 완전탐색**
  - 0초 ~ M초까지 총 M+1번 충전이 일어남 → 이동 배열 0번 인덱스에 '정지(0)'를 넣어 0초 충전을 같은 루프로 처리
  - 매 초마다 [이동 → 각 사용자가 접속 가능한 BC 표시 → 최적 배정 → 누적]
- **최적 배정**: A가 고를 BC(a) × B가 고를 BC(b)의 모든 쌍을 이중 for문으로 탐색
  - `-1` = "안 고름"을 후보에 포함 → 한쪽이 범위 안에 BC가 하나도 없을 때도 조합이 사라지지 않게 함
  - 같은 BC 동시 접속이면 반씩 나누므로 합은 P 하나만 더함
  - 서로 다른 BC면 각자 P를 그대로 더함

# 시간복잡도

- 매 초: 범위 판정 O(A) + 조합 탐색 O((A+1)²)
- 전체: **O(M · A²)** → 최대 100 × 81 ≈ 8,100 연산 (TC당), 매우 여유

# 어려웠던 점 / 배운점
두 스마트폰의 충전량 최대값을 구할떄 2중 for문으로 될 수 있는 조합을 모두 구한 뒤 최대를 구했는데,
이 문제에서는 무선층전기가 최대 4개라서 시간복잡도가 안터진다.

top2 메서드를 만들어서 각 A,B의 최대 값 두번째 값까지 구함
1. A, B 각각 접속 가능한 BC 중 P 기준 1순위, 2순위를 구합니다. 없으면 -1로 두고 P는 0으로 취급합니다.
2. 1순위가 다르면 각자 1순위를 가져갑니다. → P[A1] + P[B1]
3. 1순위가 같으면 한 명은 1순위를 쓰고, 나머지 한 명은 자기 2순위로 내려갑니다. 둘 중 2순위가 더 큰 쪽이 양보합니다. → P[X] + max(P[A2], P[B2])
