## 1️⃣ 문제 접근 방식

#### 📌 사용 알고리즘 - HashMap + 정렬

장르별 총 재생수와 장르별 곡 목록을 각각 `HashMap`에 저장한 뒤, 문제 조건에 맞게 정렬해서 곡을 선택했음 !

## 2️⃣ 핵심 아이디어

🌟 장르별 총 재생수 저장

🌟 장르별 `[곡 index, 재생수]` 목록 저장

🌟 장르는 총 재생수 내림차순 정렬

🌟 장르 내부 곡은 재생수 내림차순, 같다면 index 오름차순 정렬

---

✏️ 풀이 과정

1️⃣ 전체 곡을 순회하면서 장르별 총 재생수와 곡 정보 저장

2️⃣ 장르를 총 재생수가 많은 순서대로 정렬

3️⃣ 각 장르의 곡을 재생수 기준으로 정렬

4️⃣ 각 장르에서 최대 2곡까지 선택해서 `answerList`에 추가

5️⃣ `int[]`로 변환해서 반환

## 3️⃣ 시간복잡도

`O(n log n)`

정렬 과정이 있으므로 전체적으로 `O(n log n)` !

## 4️⃣ 풀이하면서 실수했던 부분

같은 재생수인 곡은 **고유 번호가 작은 곡을 먼저 선택해야 한다는 조건**까지 정렬 기준에 넣어야 함 !

## 5️⃣ 다시 푼다면 개선하고 싶은 점

장르별 정보와 곡 정보를 하나의 클래스 등으로 묶어서 관리하면 조금 더 보기 좋게 만들 수 있을 듯 !
