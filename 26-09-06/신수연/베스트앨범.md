# 접근 방법
장르별 총 재생 횟수를 구해서, 총 재생 횟수가 많은 장르부터 순서대로 처리한다. 각 장르 안에서는 재생 횟수가 많은 노래부터 최대 2곡을 선택한다.


<br>

# 핵심 아이디어
- `genres`, `plays`를 순회하며 장르별 총 재생 횟수(`total`)와, 장르별 (인덱스, 재생 횟수) 리스트(`info`)를 각각 저장한다.
- 각 장르의 리스트를 재생 횟수 내림차순, 재생 횟수가 같으면 인덱스 오름차순으로 정렬한다.
- `total`에서 총 재생 횟수가 가장 큰 장르를 찾아 처리한 뒤 `total`에서 제거하는 과정을, 장르 개수만큼 반복한다.
- 처리할 장르가 정해지면 해당 장르의 정렬된 리스트에서 앞에서부터 최대 2곡의 인덱스를 `answer`에 추가한다.

    
<br>

# 시간복잡도
- 시간복잡도: O(n log n + g²) — n은 곡 수, g는 장르 수. 정렬에 O(n log n), 최댓값 장르를 매번 전체 순회로 찾는 `searchMax`가 장르 수만큼 반복되면서 O(g²)이 추가됨
- 공간복잡도: O(n) — `total`, `info`에 모든 곡 정보를 저장
<br>
