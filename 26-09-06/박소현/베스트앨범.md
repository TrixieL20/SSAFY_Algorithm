# 문제 접근 방식
Map을 사용해서 데이터를 저장하자.

# 핵심 아이디어
장르별 플레이 횟수를 정렬해야하기 때문에 장르별 플레이 횟수는 배열로 관리하기
- 단, 정렬 시 실제로 사용하는 인덱스만 정렬하기

# 복잡도
## 시간 복잡도
O(N * (M * L + logN))
- 장르 탐색 (indexOf): O(N * M * L)
- 장르 정렬 (Arrays.sort): O(M logM)
- 곡 정렬 (Collections.sort): O(N logN)
- 앨범 선곡 루프: O(M)

## 공간 복잡도
O(N + M * L)
- genreArr: O(M * L)
- songByGenre: O(N + M)
- playsByGenre, answer: O(M)
