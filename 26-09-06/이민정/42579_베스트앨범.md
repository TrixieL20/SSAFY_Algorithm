# 접근 방법

문제를 처음 읽었을 때는 **장르별로 노래를 분류하고 각 장르의 총 재생 횟수를 기준으로 장르를 정렬한 뒤, 장르별로 재생 횟수가 높은 노래를 최대 2개씩 선정**하는 방식으로 접근했다.

처음에는 문제의 조건을 대충 읽고 모든 곡을 정렬해서 처리하면 된다고 생각했다. 이후 문제를 다시 확인하면서 **각 장르에서 최대 2곡만 선정하면 된다**는 조건을 알게 되었고 우선순위 큐를 사용해 장르마다 상위 2곡만 유지하는 방법도 고민했다.

다만 이번 문제에서는 전체 노래를 장르별로 분류한 뒤 정렬하는 방식으로도 충분히 해결할 수 있다고 판단했다. 따라서 **장르별 총 재생 횟수와 노래 목록을 각각 관리하고 정렬을 통해 우선순위에 맞는 곡을 선택하는 방식**으로 구현했다.

<br>

## 자료구조

### 1. `Map<String, List<Integer>> map`

```java
Map<String, List<Integer>> map = new HashMap<>();
```

장르별로 노래의 **고유번호(인덱스)**를 저장하기 위해 사용했다.

ex)

```text
genres = ["classic", "pop", "classic", "classic", "pop"]
plays  = [500, 600, 150, 800, 2500]
```


```text
classic → [0, 2, 3]
pop     → [1, 4]
```

노래의 재생 횟수 자체를 저장하지 않고 **인덱스를 저장한 이유는** 나중에 `plays[index]`를 통해 재생 횟수를 확인하면서 정렬하기 위해서다.

### 2. `Map<String, Integer> genreSum`

```java
Map<String, Integer> genreSum = new HashMap<>();
```

장르별 **총 재생 횟수**를 저장하기 위해 사용했다.

ex)
```text
classic → 1450
pop     → 3100
```

이 값을 기준으로 장르를 정렬하면 베스트앨범에 수록할 장르의 순서를 결정할 수 있다.

<br>

# 핵심 아이디어

## 1. 장르별로 노래를 분류하고 총 재생 횟수를 계산한다

```java
for (int i = 0; i < genres.length; i++) {
    map.computeIfAbsent(genres[i], k -> new ArrayList<>()).add(i);

    genreSum.put(
        genres[i],
        genreSum.getOrDefault(genres[i], 0) + plays[i]
    );
}
```

여기서 `Map`의 함수형 메서드 사용법이 처음에는 헷갈렸다.

특히 `computeIfAbsent()`는 단순히 값을 넣는 메서드가 아니라 **해당 키가 없을 때만 새로운 값을 생성하고 기존 키가 있으면 기존 값을 반환하는 메서드**라는 점을 이해하는 것이 중요했다.

```java
map.computeIfAbsent(genres[i], k -> new ArrayList<>()).add(i);
```

이 코드는 다음과 같은 의미다.

```java
if (!map.containsKey(genres[i])) {
    map.put(genres[i], new ArrayList<>());
}

map.get(genres[i]).add(i);
```

즉, 장르가 처음 등장하면 리스트를 생성하고 이미 존재하는 장르라면 기존 리스트에 노래의 인덱스를 추가한다.

또한 `getOrDefault()`를 사용하면 장르가 처음 등장했을 때의 총 재생 횟수를 간단하게 계산할 수 있다.

```java
genreSum.put(
    genres[i],
    genreSum.getOrDefault(genres[i], 0) + plays[i]
);
```

<br>

## 2. 총 재생 횟수를 기준으로 장르를 정렬한다

```java
List<String> sortedGenres = new ArrayList<>(genreSum.keySet());

sortedGenres.sort((a, b) ->
    Integer.compare(genreSum.get(b), genreSum.get(a))
);
```

`genreSum`의 키만 리스트로 가져온 뒤, 각 장르의 총 재생 횟수를 비교하여 내림차순으로 정렬했다.

여기서 `Integer.compare()`를 사용한 이유는 **정렬 비교에서 단순 뺄셈보다 안전하고 명확하기 때문**이다.

```java
Integer.compare(genreSum.get(b), genreSum.get(a))
```

<br>

## 3. 각 장르의 노래를 재생 횟수 내림차순으로 정렬한다

```java
for (String genre : map.keySet()) {
    List<Integer> songs = map.get(genre);

    songs.sort((a, b) -> {
        if (plays[a] == plays[b]) {
            return Integer.compare(a, b);
        }

        return Integer.compare(plays[b], plays[a]);
    });
}
```

노래는 **재생 횟수가 높은 순서**로 정렬하고 재생 횟수가 같다면 **고유번호가 낮은 순서**로 정렬했다.

```text
classic → [3, 0, 2]
pop     → [4, 1]
```

처음에는 정렬 비교에서 `b - a`처럼 인덱스를 비교하는 실수를 했다. 하지만 이 문제에서 정렬해야 하는 것은 **노래의 고유번호가 아니라 재생 횟수**이므로, `plays[b] - plays[a]`를 사용해야 한다는 점을 다시 확인했다.

<br>

## 4. 정렬된 장르 순서대로 최대 2곡을 선택한다

```java
for (String genre : sortedGenres) {
    List<Integer> songs = map.get(genre);

    for (int i = 0; i < Math.min(2, songs.size()); i++) {
        result.add(songs.get(i));
    }
}
```

장르별 노래를 모두 정렬한 뒤, 각 장르에서 **앞의 2곡만 선택**했다.

처음에는 문제의 조건을 대충 읽고 모든 곡을 정렬해서 처리하면 된다고 생각했지만 다시 확인하면서 **각 장르에서 최대 2곡만 선정한다는 조건**이 핵심이라는 것을 알게 되었다.

따라서 정렬된 리스트에서 `songs.get(0)`, `songs.get(1)`을 선택하는 방식으로 해결할 수 있었다.

<br>

# 시간복잡도

전체 노래 수를 **N**, 장르 수를 **K**라고 하자.

### 1. 장르별 분류 및 총 재생 횟수 계산

```java
for (int i = 0; i < genres.length; i++)
```

→ **O(N)**

### 2. 장르 정렬

장르 K개를 정렬하므로 → **O(K log K)**

### 3. 장르별 노래 정렬

각 장르의 노래 수를 `n₁, n₂, ..., nₖ`라고 하면:

```text
O(n₁ log n₁) + O(n₂ log n₂) + ... + O(nₖ log nₖ)
```

각 장르의 노래 수의 합은 N → **O(N log N)**

### 4. 최종 결과 생성

각 장르에서 최대 2곡만 선택하므로:

→ **O(K)**

### 최종 시간복잡도

```text
O(N) + O(K log K) + O(N log N) + O(K)
```
> **O(N log N)**

<br>

공간복잡도는 장르별 노래 목록과 정렬된 장르 목록을 저장하므로

> **O(N + K)**

<br>

# 배운 점

* `Map`의 `computeIfAbsent()`, `getOrDefault()` 사용법을 익혔다.
* `List.sort()`는 전체 리스트를 정렬하는 데 사용하며, 정렬 기준을 람다식으로 지정할 수 있다는 점을 다시 확인했다.
* 정렬 비교에서는 **무엇을 기준으로 정렬해야 하는지**가 중요하다.

    * 장르 정렬 → 총 재생 횟수
    * 노래 정렬 → 재생 횟수
    * 재생 횟수가 같으면 → 고유번호
* 문제에서 **“최대 2개”**라는 조건을 놓치지 않고 필요한 만큼만 선택하는 것이 중요하다는 것을 배웠다.
* 우선순위 큐를 사용하면 각 장르에서 상위 2곡만 유지하는 방식도 가능하지만 이번 문제에서는 전체 노래를 장르별로 분류하고 정렬하는 방식으로도 충분히 해결할 수 있었다.

<br>

# 실수한 부분

* `computeIfAbsent()`의 사용법이 헷갈려서 처음에 문법적으로 잘못 작성했다.
* `List.sort()`의 비교식에서 재생 횟수가 아닌 인덱스를 비교하는 실수를 했다.
* 재생 횟수가 같을 때 고유번호 오름차순이라는 조건을 놓칠 뻔했다.
* 각 장르에서 최대 2곡만 선정하면 되는데 처음에는 모든 곡을 정렬해서 처리하면 된다고 생각했다.
* `map.keySet()`과 `sortedGenres`을 코드를 작성하며 혼용했다.

    * `map.keySet()` → 장르의 키 목록
    * `sortedGenres` → 총 재생 횟수 기준으로 정렬된 장르 목록
* `List<Integer>`를 `int[]`로 변환하는 과정에서 반환 타입을 맞추는 부분도 확인했다.
