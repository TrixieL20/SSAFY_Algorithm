# 접근 방법 / 핵심 아이디어

문제에서 베스트 앨범에 들어가는 노래의 순서를 결정하는 조건이 여러 개였기 때문에, 각 조건에 필요한 정보를 먼저 나누어 생각했습니다.
먼저 장르의 순서를 결정하기 위해서는 장르별 총 재생 횟수가 필요하기 때문에 Map<String, Integer>를 사용하여 장르별 재생 횟수의 합을 저장했습니다.
또 각 장르에서 재생 횟수가 가장 많은 노래를 최대 2개 선택해야 하기 때문에, Map<String, List<Song>>을 사용하여 장르별로 노래의 고유 번호(index)와 재생 횟수(play)를 저장했습니다.
이후 문제에서 주어진 조건에 맞게 두 단계로 정렬했습니다.

1. 장르별 총 재생 횟수를 기준으로 내림차순 정렬
2. 각 장르에 포함된 노래를
   - 재생 횟수 기준 내림차순
   - 재생 횟수가 같다면 고유 번호 기준 오름차순으로 정렬

정렬이 끝난 후 장르 순서대로 순회하면서 각 장르에서 최대 2개의 노래를 선택하여 정답에 추가했습니다.

즉,

장르별 정보 저장 → 장르 정렬 → 장르 내부 노래 정렬 → 최대 2곡 선택



<br>

# 시간복잡도

O(N log N)

<br>

# 어려웠던 점 / 배운점


- HashMap을 이용한 데이터 그룹화 및 집계
- Map의 value로 List를 사용하는 방법
- 여러 정렬 조건을 Comparator로 구현하는 방법
- 문제에서 주어진 정렬 조건의 우선순위를 나누어 생각하는 방법
을 연습할 수 있었습니다.
