# 접근 방법 / 핵심 아이디어
단어의 길이와, 단어 개수가 많지 않기에 현재 단어와 "한 글자" 차이나는 단어들을 구하는 n^2 시간복잡도 소요를 해도 괜찮다 판단했음.

큐에 있는 단어를 꺼내고 그 꺼낸 단어를 기준으로 한 글자 차이나는 단어들을 큐에 또 넣음으로써 target 단어까지 도달하게 BFS접근했다.




<br>

# 시간복잡도
O(N^2*L)
N : 단어 개수 (최대 50)
L : 단어 길이 (최대 10)
다 최대 일시 2.6만번 연산
<br>

# 어려웠던 점 / 배운점

BFS의 접근. 사실 문제에서 BFS라고 말안했다면 풀 생각 못했을거같다.

BFS인거만 알면 쉽게 풀 수 있을거같다.
