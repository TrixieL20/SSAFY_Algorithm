# 접근 방법 / 핵심 아이디어
1. int[] {A점수, B점수, 원래인덱스} 형태로 저장해 원본 인덱스(완호 위치)를 끝까지 추적

2. A점수 기준 내림차순 정렬 -> A가 같은 요소 시작,끝 인덱스 저장 -> 이 인덱스 사이를 1번 순회해서 이 그룹 중에 maxB보다 크거나 같으면 survived에 추가 -> 이 그룹 내에서의 groupMaxB도 갱신 -> 순회 끝나면 maxB와 groupMaxB 둘중 큰거를 maxB로 갱신 -> 반복해서 최종 살아남은 요소 survived 리턴

3. 완호(원래인덱스 0)가 생존자 리스트에 있는지 확인 → 없으면 -1

4. 생존자들의 총점(A+B)을 내림차순 정렬, 동점자는 같은 순위 부여(표준 경쟁 순위: 1,2,2,4) → 완호의 순위 반환

<br>

# 시간복잡도

전체 : O(N log N) 
getSurvivedList: 정렬 O(N log N) + 그룹 순회 O(N) = O(N log N)
getRanking: 정렬 O(N log N) + 순위 계산 O(N) = O(N log N)

<br>

# 어려웠던 점 / 배운점

처음부터 접근한 알고리즘이 문제 답을 내는데 맞지 않았었다.
디버깅하면서 찾은 반례들을 보며 고쳐도 찾은 반례만 풀려서 그리디 문제 풀듯이 되어버렸다.
문제 의도에 맞는 접근아 아닌걸 알아채고 빨리 갈아 엎는게 맞는거같고, 접근 하기전 충분히 생각해야겠다.
