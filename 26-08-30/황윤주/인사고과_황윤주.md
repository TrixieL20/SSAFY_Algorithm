# 접근 방법
- 모든 직원을 서로 비교하면 O(N²)이 되어 비효율적이기 때문에 정렬을 활용하여 비교 횟수를 줄임
- 근무 태도 점수를 기준으로 내림차순 정렬하고, 근무 태도 점수가 같다면 동료 평가 점수를 오름차순으로 정렬
- 정렬 후 앞에서부터 확인하면서 지금까지 등장한 동료 평가 점수의 최댓값을 저장하여, 현재 직원이 두 점수 모두 낮은 직원인지 판단
- 완호가 인센티브를 받을 수 있는 직원이라면 완호보다 총점이 높은 직원의 수를 이용해 등수를 계산



<br>

# 핵심 아이디어

- 근무 태도 점수를 내림차순, 동료 평가 점수를 오름차순으로 정렬
- max 변수에 현재까지 확인한 동료 평가 점수의 최댓값을 저장
- 현재 직원의 동료 평가 점수가 max보다 작다면, 현재 직원보다 근무 태도 점수와 동료 평가 점수가 모두 높은 직원이 존재하므로 인센티브 대상에서 제외
- 탈락하지 않은 직원 중 완호의 총점보다 높은 총점을 가진 직원의 수를 세어 완호의 등수를 계산

<br>

# 시간복잡도





```
O(N log N)
```

<br>

# 어려웠던 점

- 처음에는 각 직원을 다른 모든 직원과 비교하여 인센티브 대상인지 확인하려고 했지만, 모든 직원을 서로 비교하면 O(N²)이 되어 비효율적이었다.
- 두 점수가 모두 높은 직원을 빠르게 찾기 위해 어떤 기준으로 정렬해야 하는지 생각하는 부분이 어려웠다.

<br>

# 배운 점
- 완전탐색으로 O(N²)이 되는 문제도 정렬을 통해 비교 기준을 하나 고정하면 효율적으로 해결할 수 있다.
