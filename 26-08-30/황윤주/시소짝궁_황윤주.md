# 접근 방법
- 시소의 좌석은 2, 3, 4의 거리만 사용할 수 있기 때문에 두 사람의 몸무게 비율이 1:1, 2:3, 1:2, 3:4인 경우 짝궁이 될 수 있다.
- 몸무게가 같은 사람이나 특정 비율의 몸무게를 가진 사람의 수를 빠르게 확인하기 위해 HashMap을 사용
- 현재 사람보다 앞에서 등장한 사람들의 몸무게와 짝궁이 될 수 있는지 확인한 후, 현재 사람의 몸무게를 HashMap에 저장하는 방식으로 구현



<br>

# 핵심 아이디어

- HashMap<몸무게, 해당 몸무게를 가진 사람 수>를 사용하여 각 몸무게의 등장 횟수를 저장
- map.getOrDefault()를 사용하여 현재 사람과 짝궁이 될 수 있는 이전 사람의 수를 answer에 더함 
- 짝궁 여부를 확인한 후 현재 사람을 HashMap에 추가하여 자기 자신이 짝궁으로 계산되지 않도록 함
- 같은 몸무게를 가진 사람도 서로 짝궁이 될 수 있기 때문에 HashMap의 value를 단순 존재 여부가 아닌 사람의 수로 관리

<br>

# 시간복잡도





```
O(N)
```

<br>

# 어려웠던 점

- 같은 몸무게를 가진 사람이 여러 명 있을 수 있기 때문에 단순히 몸무게의 존재 여부를 확인하는 것이 아니라, 각 몸무게를 가진 사람의 수를 HashMap에 저장해야 하는 부분이 헷갈렸다 

<br>

# 배운 점
- 같은 값이 여러 번 등장하는 문제에서는 HashMap을 이용해 값의 등장 횟수를 관리할 수 있다.
- 단순 완전탐색 대신 HashMap을 활용하면 모든 사람을 서로 비교하지 않고도 O(N)으로 해결할 수 있다.
