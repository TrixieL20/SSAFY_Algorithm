# 문제 접근 방식
몸무게가 최대 10만개이기 때문에, 중복이 되는 것을 묶자.

# 핵심 아이디어
- 몸무게 별로 Map을 만들어 사람 수 관리
- Map의 Key 값을 Array로 만들어 다른 몸무게들과 비교
- 몸무게를 오름차순 정렬 후 비교
- 시소짝꿍이 되는 경우
  - 1:1 같을 때는 n(n-1)/2
  - 1:2, 2:3, 3:4 

# 복잡도
## 시간 복잡도
O(N + M^2)
- Map 삽입: O(N) => N: weights 길이
- for문: O(M^2) => M: weight 종류 갯수

## 공간 복잡도
O(M)

# 풀이하면서 실수했던 부분
- for문 돌릴 때, 바깥쪽 for문을 마지막까지 돌리는 게 아니라 weights.length - 1까지만 돌리도록 해서, 마지막 원소의 몸무게가 같은 경우를 계산하는 것을 놓치게 되었다.
  for문에서 어떤 연산이 되고 있는지 잘 생각해서 범위 설정을 해야겠다.
