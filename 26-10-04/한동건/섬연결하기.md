# 접근 방법 / 핵심 아이디어

서로소집합 개념으로 풀었다.
costs[][]를 비용이 낮은 순으로 정렬해서 시작 섬이 속하는 집합과 끝나는 섬이 속한 집합이 같다면(연결되었다면) 스킵,
두 섬이 속한 집합이 연결되지 않았다면 union()하여 연결한다.


<br>

# 시간복잡도

정렬 : O(ElogE)
union-find : O(α(n)), 역 아커만 함수로 사실상 상수

최종 시간복잡도 : O(ElogE)

<br>

# 어려웠던 점 / 배운점
로직 실수 : union()을 할때 parents[bRoot] = aRoot; 로 다른 섬 집합의 대표 노드의 부모를 바꿔야하는데 
parents[b] = aRoot; 를 해서 다른 섬의 부모를 바꿔버렸다. 까먹지 말자

효율성 :
처음에는 경로 압축을 하지 않았다. find()함수리턴을 재귀할때마다 부모노드를 업데이트 하도록 바꿨음.
