# 접근 방법

백트래킹 알고리즘을 사용해 모든 방문 경로를 구한다.

<br>

# 핵심 아이디어

- 백트래킹 사용
- 티켓을 모두 사용해서 방문할 수 있는 경로를 공백 기준으로 나눠 String으로 저장하고, 결과를 result 리스트에 저장한다.
- 모든 경우의 수를 구하면 result를 정렬해 제일 첫 번째에 저장 된 요소를 답으로 리턴한다.

<br>

# 시간복잡도

```
O(N! × N²)
```

<br>

# 어려웠던 점

처음에는 HashMap을 사용해 Key는 String으로, Value는 PriorityQueue를 사용해 방문 가능한 경로를 저장하고, BFS 알고리즘으로 풀이를 진행하려 했습니다.
방문한 노드는 Set에 저장해 구분하려 했지만, 경로가 존재할 때 노드 중복 방문이 가능하다는 걸 알았고, 해당 방법으로 풀기 어렵다고 느껴 다른 방법을 생각하는 데 시간이 오래 걸렸습니다.
