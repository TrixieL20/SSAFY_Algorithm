# 접근 방법

- BFS 알고리즘을 적용해 풀이
- moveX와 moveY를 사용해 다음으로 방문할 위치를 탐색

<br>

# 핵심 아이디어

- Queue<int[]>를 사용해 방문 좌표 및 이동 수 저장
- moveX, moveY를 사용해 상하좌우로 이동 가능한 좌표만 queue에 저장
- 방문한 좌표는 visited를 true로 저장




<br>

# 시간복잡도

```
O(N * M)
```

<br>

# 어려웠던 점

- 행과 열이 같은 크기라 생각하고 풀이를 진행해서 어느 부분이 잘못됐는지 찾는데 시간이 많이 쓰였습니다. 

<br>

# 배운 점

- 좌표 방향 전환 문제는 그래프 문제에서 자주 나오는 유형이기 때문에 다양한 문제에 적용해 보며 연습하는게 중요할 것 같습니다.
