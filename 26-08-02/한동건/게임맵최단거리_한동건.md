# 문제 정보

프로그래머스 / Lv2 / 게임 맵 최단거리

<br>

# 접근 방법


전형적인 BFS 문제라고 생각해서 BFS 선택했습니다

<br>

# 핵심 아이디어

4방향을 한번씩가게하여서 갔을때 지점까지의 거리를 계속 저장해 도착지까지 돌렸습니다 

<br>

# 시간복잡도

```
O(N)
```

<br>

# 어려웠던 점

자바로 bfs문제 풀기는 처음이라 메서드 찾기가 힘들었습니다.

처음 구현했을때 정확성은 통과하는데 효율성을 통과하지 못해서, 
처음엔 큐에 넣는걸 객체를 따로 생성한게 원인인가해서 int[3] 배열로 바꾸고 10배정도 빨라졌지만 통과하지 못했습니다.

원인은 방문한 격자처리를 큐에 넣기전이 아닌 큐를 꺼내고 나서 처리를 해버려서 시간초과가 났습니다.
큐에 넣기 전 방문 처리를 안 하면, 큐에서 아직 안 꺼내진 노드를 다른 노드가 중복으로 큐에 계속 넣기 때문에 시간 초과 발생했습니다

<br>

# 배운 점

객체보다 배열이 생각보다 빠르다.
중복으로 들어가는지 잘보자.
