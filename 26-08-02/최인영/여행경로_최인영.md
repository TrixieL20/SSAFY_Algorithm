## 1️⃣ 문제 접근 방식
#### 📌 사용 알고리즘 - DFS + 백트레킹

<b>깊이 우선 탐색</b>하되, 선택된 지점에서 주어진 항공권 모두 이용하는 경로 안 나오는 경우 <b>백트레킹 처리</b>했음.

↪️ 다음 이동 지점 선택 → 다시 dfs 함수 시행했을 때  문제에 주어진 항공권 항공권을 다 쓰지 못하고 막히는 경우 
→ 해당 지점 방문 취소하고 최종 여행 경로 리스트에서 빼도록 백트레킹 처리 ! 

## 2️⃣ 핵심 아이디어

🌟 [출발지, 도착지] 형식의 항공권들 미리 알파벳 순 정렬

🌟 DFS로 소지한 항공권 모두 소진할 수 있는 경로 찾음 ! 

🌟 현 위치[출발지, 도착지]의 도착지를 출발지로 하는 다음 이동 후보 지점으로 이동했을 때, 해당 지점에서는 dfs 이어가도 모든 항공권 소진 불가능한 경우 백트레킹으로 방문 처리 취소

---
✏️ 풀이 과정

1️⃣ [출발지, 도착지] 형식의 항공권들을 알파벳 오름차순 정렬
    
    → 출발지 먼저 비교
    → 출발지 같은 경우 도착지 비교해 오름차순 정렬
    
2️⃣ 최초 출발지는 ICN 고정이므로 최종 여행 경로 담을 list answer에 ICN 추가

→ DFS 수행: DFS 함수 내에서 정렬된 항공권 모두 소진되도록 여행 경로 찾음 

3️⃣ DFS 함수
    
 만약 해당 항공권으로 나머지 모든 항공권 써서 여행 가능한 경우 return true, 그게 안 돼서 해당 항공권 사용 취소해야 하는 경우 return
    
    A. 여태 사용된 항공권 수가 전체 항공권 수와 같은 경우
    
    ↪️ 문제 조건대로 항공권 다 사용한 경로 나온 것이므로 return true
    

    B. 전체 항공권 수만큼 반복문 실행
    
    B-1. 이미 해당 항공권을 사용(visited)한 경우, 다음 항공권의 출발지가 현재 항공권의 도착지와 다른 경우는 continue
    
    B-2. 이외의 경우 해당 항공권 사용(방문) 처리 + 최종 여행 경로 list(answer)에 그 항공권의 도착지 추가
    
    ↪️ 해당 항공권으로 dfs 함수 다시 호출해 true 돌아오면 그 경로로 여행 가능하단 의미 ➡️ true 반환
    
    ↪️ 그러나 해당 항공권으로 dfs 함수 넣어 봤을 때 false 돌아오면 해당 경로로는 모든 항공권 소진하는 여행 경로 짤 수 없단 의미 ➡️ 했던 처리 번복하고 백 트레킹 !
   
## 3️⃣ 시간복잡도
`O(n x n!)`

## 4️⃣ 풀이하면서 실수했던 부분
항공권을 전부 다 소진해야 한다는 문제 조건에 따라, dfs 하더라도 백트레킹 필요하단 부분 놓쳐서 항공권 다 쓰지 못한 케이스 생겼음 !
