# 문제 접근 방식
DFS로 풀면 될 것이라고 생각했다.

# 핵심 아이디어
Map의 Key로 출발지, Value로 목적지 배열을 저장한 후 DFS를 하려고 했다.
이 때 방법이 여러가지가 있다면, 알파벳이 빠른 순으로 답을 작성해야하기 때문에 Value 값인 배열을 정렬해주었다.

# 시간복잡도
O(N!) => 모든 공항이 전부 연결되어 있는 경우 모든 경우의 수를 탐색한다.

# 풀이하면서 실수했던 부분
1. 문제에서 티켓을 다 사용하라고 했으나 까먹고 도시를 다 가는 방식으로 풀었다.
2. 무조건 출발지는 "ICN"으로 정해져 있는데 그 부분을 누락했다.

# 다시 푼다면 개선하고 싶은 점
1. 일단, 이거는 풀이 실패한 코드다. 다시 논리를 재정비해 풀어보고 싶다.
2. Map이나 Set을 사용하는 법을 좀 더 알아보고 코드를 깔끔하게 다듬고 싶다.
