# 문제 접근 방식
DFS/BFS로 풀면 되겠다고 생각했다.

# 핵심 아이디어
BFS로 풀면 목적지까지 도달하는 최단 거리를 좀 더 효율적으로 풀 수 있을 것이다.
왜냐하면 BFS가 너비우선탐색이므로 탐색한 노드들은 반드시 출발지로부터의 최단거리를 가지게 된다.

# 시간복잡도
O(N * M) => 큐에 각 칸들이 한 번씩만 들어간다.

# 풀이하면서 실수했던 부분
1. 처음에 별 생각 없이 DFS로 풀었는데, 최단 거리는 BFS가 더 효율적이라는 것을 잊지 말자.
2. LinkedList를 처음 써봐서 q.push가 당연히 맨 뒤에 추가인 줄 알았는데 offer라고 따로 있었다.
