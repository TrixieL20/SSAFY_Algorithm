# 접근 방법

DFS를 이용해 전체 식재료 중 N / 2개를 선택하여 A 음식에 배정한다. 선택하지 않은 나머지 식재료는 자동으로 B 음식에 배정한다.

A 음식에 들어갈 식재료를 모두 선택하면 두 음식에 포함된 식재료 쌍의 시너지를 각각 계산한다. 두 음식의 맛 차이를 구하고, 기존 최솟값과 비교하여 정답을 갱신한다.

모든 조합을 탐색한 후 최소 맛 차이를 반환한다.

<br>

# 핵심 아이디어
- DFS와 조합을 이용해 N개의 식재료 중 N / 2개를 선택한다.
- 선택한 식재료는 A 음식, 선택하지 않은 식재료는 B 음식으로 구분한다.
- 각 음식의 맛은 해당 음식에 포함된 모든 식재료 쌍의 시너지 S_ij를 합산하여 계산한다.
- 시너지는 S_ij와 S_ji를 모두 더해야 한다.
- 두 음식의 맛 차이의 절댓값을 계산하고 최솟값을 갱신한다.

<br>

# 시간복잡도
- 시간복잡도: O(n^2)
- 공간복잡도: O(N^2)
