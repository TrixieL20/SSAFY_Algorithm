# 문제 정보

| 항목 | 내용 |
|---|---|
| 문제 이름 | 퍼즐 조각 채우기 |
| 난이도 | Level 3 |
| 플랫폼 | 프로그래머스 |

<br>

# 접근 방법

BFS를 이용해 게임 보드의 빈 영역과 테이블의 퍼즐 조각을 각각 추출한다. 탐색한 영역은 좌표 목록으로 저장하고, 좌표의 최솟값을 빼서 도형의 위치와 관계없이 모양을 비교할 수 있도록 정규화한다.

각 빈 영역에 대해 아직 사용하지 않은 퍼즐 조각을 탐색한다. 조각의 칸 개수가 빈 영역과 같으면 90도씩 회전하며 모양이 일치하는지 확인한다. 일치하는 조각을 찾으면 해당 조각을 사용 처리하고, 빈 영역의 칸 개수를 정답에 더한다.

모든 빈 영역을 확인한 뒤 채운 칸의 총개수를 반환한다.

<br>

# 핵심 아이디어
- BFS를 이용해 상하좌우로 연결된 빈 영역과 퍼즐 조각을 각각 추출한다.
- 각 영역을 좌표 목록으로 저장하고, 최솟값을 빼서 좌표를 정규화한다.
- 정규화된 좌표를 정렬하여 두 도형의 모양을 비교한다.
- 퍼즐 조각을 90도씩 회전하며 최대 4가지 방향을 확인한다.
- 빈 영역과 조각의 칸 개수가 같고 모양도 일치하면 해당 조각을 사용 처리한다.
- 하나의 퍼즐 조각은 한 번만 사용할 수 있으며, 채운 칸의 개수를 누적하여 정답을 구한다.

<br>

# 시간복잡도
- 시간복잡도: O(N^4)
- 공간복잡도: O(N^2)
