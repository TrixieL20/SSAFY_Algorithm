# 접근 방법 / 핵심 아이디어

N개 재료중 N/2개를 뽑은거로 A음식, 나머지 재료로 B음식을 만들어서
 매 조합마다 점수를 내서 최소를 구했다.


<br>

# 시간복잡도
O(C(N, N/2) × N^2)

조합개수 : O(C(N,N/2))
curDiff() : O(N^2)

<br>

# 어려웠던 점 / 배운점
예시가 4개로 2개씩 재료를 나누는 예시 뿐이라, N/2로 나눈 개수중 2개만 고르는지 알았음
근데 N/2로 나눈 재료의 모든 쌍 점수를 더하는거 였다.

문제 자체는 규영이와 인영이, 양궁대회 문제같이 조합을 구해서 최소나 최대 값을 구하는 문제와 같다고 느꼈다.
