# 접근 방법
- 게임판에서 0으로 연결된 빈칸을 BFS로 탐색한다.
- 테이블에서 1로 연결된 퍼즐 조각을 BFS로 탐색한다.
- 각 빈칸과 퍼즐 조각의 좌표를 리스트에 저장한다.
- 좌표 정규화를 통해 서로 다른 위치에 있는 도형도 모양을 비교할 수 있도록 한다.
- 빈칸과 퍼즐 조각의 크기가 같으면 0도, 90도, 180도, 270도로 회전하면서 모양을 비교한다.
- 모양이 일치하면 퍼즐 조각을 사용 처리하고 채운 칸의 개수를 정답에 더한다.

## 자료구조
- `int[][] game_board` : 게임판의 빈칸 정보
- `int[][] table` : 퍼즐 조각의 위치 정보
- `boolean[][] visited` : BFS 탐색 시 방문 여부 저장
- `Queue<int[]>` : BFS로 연결된 좌표를 탐색하기 위해 사용
- `List<List<int[]>> blanks` : 게임판의 빈칸 좌표 저장
- `List<List<int[]>> blocks` : 테이블의 퍼즐 조각 좌표 저장
- `boolean[] used` : 이미 사용한 퍼즐 조각인지 확인

# 핵심 아이디어

### 1. BFS로 연결된 칸 찾기

- 상하좌우로 연결된 같은 값의 칸을 하나의 도형으로 묶는다.
- 게임판에서는 `0`, 테이블에서는 `1`을 기준으로 탐색한다.

### 2. 좌표 정규화

- 도형의 모든 좌표에서 최소 x좌표와 최소 y좌표를 빼준다.
- 도형의 위치가 달라도 동일한 모양인지 비교할 수 있다.


### 3. 퍼즐 조각 회전

- 퍼즐 조각을 90도씩 회전하며 빈칸과 비교한다.
- 회전 공식은 `(x, y) → (y, -x)`이다.
- 회전 후에는 다시 좌표를 정규화한다.



# 시간복잡도

**O(N² + B × P × 4 × K²)**

- `N` : 게임판의 한 변의 길이
- `B` : 빈칸 도형의 개수
- `P` : 퍼즐 조각의 개수
- `K` : 도형을 구성하는 최대 칸 수

BFS로 모든 칸을 탐색하는 데 `O(N²)`이 필요하다.

이후 빈칸과 퍼즐 조각을 비교하며, `isSame()`에서 좌표를 이중 반복문으로 확인하므로 최악의 경우 `O(K²)`이 소요된다.

# 배운 점
- BFS를 활용하면 격자에서 연결된 칸을 하나의 도형으로 추출할 수 있다.
- 좌표 정규화를 통해 위치가 다른 도형도 동일한 기준으로 비교할 수 있다.
- 2차원 좌표를 회전하는 공식을 활용하면 실제 배열을 회전하지 않고도 도형의 모양을 비교할 수 있다.
- 퍼즐 조각은 한 번만 사용할 수 있으므로 `used[]` 배열로 사용 여부를 관리해야 한다.

# 실수한 부분
- BFS로 찾은 좌표를 그대로 비교하면 위치가 다른 동일한 도형을 구분하지 못하므로 정규화가 필요하다.
- 퍼즐 조각을 회전한 뒤 다시 정규화하지 않으면 음수 좌표가 남아 비교가 잘못될 수 있다.
- 퍼즐 조각의 크기가 같더라도 모양이 다를 수 있으므로 좌표까지 비교해야 한다.
