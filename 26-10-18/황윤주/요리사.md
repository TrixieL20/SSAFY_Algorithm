# 접근 방법

- N개의 식재료를 각각 N/2개씩 선택하여 A음식과 B음식으로 나눈다.
- 조합을 이용하여 A음식에 사용할 N/2개의 식재료를 선택한다.
- `boolean[] selected` 배열을 사용하여 선택한 재료와 선택하지 않은 재료를 구분한다.
- 선택한 재료는 A음식, 선택하지 않은 재료는 B음식에 사용한다.
- 각 음식에 포함된 식재료들의 시너지 합을 계산한다.
- 두 음식의 시너지 차이의 절댓값을 구하고 최솟값을 갱신한다.

## 자료구조

- `int[][] foods` : 식재료 간 시너지 정보 저장
- `boolean[] selected` : A음식에 사용할 식재료의 선택 여부 저장
- `int N` : 전체 식재료의 개수
- `int answer` : 두 음식의 시너지 차이의 최솟값 저장
- `int sumA` : A음식의 시너지 합
- `int sumB` : B음식의 시너지 합

<br>

# 핵심 아이디어

### 1. 조합으로 식재료 선택

- N개의 식재료 중 N/2개를 선택한다.
- 순서는 중요하지 않으므로 순열이 아닌 조합을 사용한다.
- `selected[i] = true`이면 A음식, `false`이면 B음식에 포함된다.

### 2. 식재료 시너지 계산

- 같은 음식에 포함된 식재료끼리 시너지를 계산한다.
- 식재료 i와 j의 시너지는 `foods[i][j] + foods[j][i]`이다.
- `j = i + 1`부터 탐색하여 동일한 식재료 쌍을 중복 계산하지 않는다.


### 3. 최소 차이 갱신

- A음식과 B음식의 시너지 차이를 계산한다.
- 모든 조합을 탐색하면서 가장 작은 차이를 정답으로 저장한다.

<br>

# 시간복잡도
**O(C(N, N/2) × N²)**

- `N` : 전체 식재료의 개수
- `C(N, N/2)` : N개의 식재료 중 N/2개를 선택하는 조합의 개수

# 배운 점

- N개의 원소를 두 그룹으로 나누는 문제는 조합으로 해결할 수 있다.
- `boolean[] selected`를 사용하면 선택한 그룹과 선택하지 않은 그룹을 쉽게 구분할 수 있다.
- 조합을 구현할 때 `start`를 사용하면 중복 없이 원소를 선택할 수 있다.
- 백트래킹에서는 재귀 호출 후 선택 상태를 원래대로 복구해야 한다.
- 시너지처럼 두 원소 사이의 관계를 계산할 때는 이중 반복문을 활용할 수 있다.

# 실수한 부분

- A음식에 포함되지 않은 식재료는 자동으로 B음식에 포함된다는 점을 이해해야 한다.
- 식재료 i와 j의 시너지는 `foods[i][j]`만 사용하는 것이 아니라 `foods[i][j] + foods[j][i]`로 계산해야 한다.
- 조합을 탐색할 때 `comb(i + 1, depth + 1)`로 호출해야 동일한 식재료를 중복 선택하지 않는다.
- 재귀 호출 후 `selected[i] = false`로 복구하지 않으면 다음 조합에 영향을 준다.
- 테스트케이스마다 `answer`와 `selected` 배열을 초기화해야 한다.
