# 문제 정보

| 항목 | 내용 |
| ----- | ------ |
| 문제 이름 | 점심 식사시간 (2383) |
| 난이도 | 모의 SW 역량테스트 |
| 플랫폼 | SWEA |

## 접근 방법

- DFS(완전탐색)를 이용해 각 사람이 이용할 계단을 선택한다.
  - 계단은 2개이므로 사람마다 0번 또는 1번 계단을 선택할 수 있다.
  - 모든 사람의 계단 배정이 완료되면 `calculateTime()`으로 이동 완료 시간을 계산한다.
- 각 사람과 배정된 계단 사이의 **맨해튼 거리**를 계산하여 계단 입구 도착 시간을 구한다.
  - `arrivalTime = |사람 행 - 계단 행| + |사람 열 - 계단 열|`
- 계단별 `PriorityQueue`에 도착 시간을 넣어 오름차순으로 처리한다.
- 계단은 동시에 최대 3명만 이용할 수 있으므로, 도착 순서에 따라 실제 진입 시간과 종료 시간을 계산한다.
- 두 계단의 마지막 종료 시간 중 큰 값을 해당 배정의 전체 소요 시간으로 정하고, 모든 배정 중 최솟값을 갱신한다.

## 핵심 아이디어

- **계단 입구에 도착한 뒤 1분이 지나야 진입할 수 있다.** 따라서 가장 빠른 진입 시간은 `arrivalTime + 1`이다.
- 계단을 이용하는 사람이 3명 이하라면 도착 후 1분 뒤 바로 진입할 수 있다.
- 4번째 사람부터는 계단의 수용 인원(3명)을 고려해야 한다. 도착 시간순으로 처리했을 때 `index - 3`번째 사람의 종료 시간을 확인하면 된다.

```java
int startTime = arrivalTime + 1;

if (index >= 3) {
    startTime = Math.max(startTime, endTime[index - 3]);
}

endTime[index] = startTime + k;
```

- `endTime[index - 3]`: 현재 사람이 들어가기 위해 앞선 사람이 계단을 비우는 시간
- `Math.max()`: 본인이 진입 가능한 시간과 자리가 비는 시간 중 늦은 시간을 선택
- `endTime[index]`: 현재 사람이 계단을 완전히 내려간 시간

예를 들어 계단 길이가 `5`, 도착 시간이 `[2, 3, 4, 5, 6]`이라면 다음과 같다.

| 사람 | 도착 시간 | 실제 진입 시간 | 종료 시간 |
| ----- | ----- | ----- | ----- |
| 1번 | 2 | 3 | 8 |
| 2번 | 3 | 4 | 9 |
| 3번 | 4 | 5 | 10 |
| 4번 | 5 | 8 | 13 |
| 5번 | 6 | 9 | 14 |

- 4번 사람은 6분에 진입할 수 있지만 계단이 가득 차 있으므로 1번 사람이 내려간 8분에 진입한다.
- 각 계단의 종료 시간 중 최댓값이 해당 배정의 전체 소요 시간이다.
- DFS로 생성한 모든 배정의 전체 소요 시간 중 최솟값이 정답이다.

## 시간복잡도

- 시간복잡도: **O(2^P × P log P)**
  - `P`: 사람 수 (최대 10명)
  - DFS로 각 사람이 선택할 계단을 배정하는 경우의 수: `2^P`
  - 각 배정에서 우선순위 큐 삽입·삭제: `O(P log P)`
  - 계단별 종료 시간 계산: `O(P)`
- 공간복잡도: **O(N² + P)**
  - 지도 저장: `O(N²)`
  - 사람 위치, 계단 배정, 우선순위 큐, 종료 시간 배열 및 DFS 호출 스택: `O(P)`
  - 계단 수는 항상 2개이므로 상수 공간으로 취급한다.
