# 접근 방법

내림차순 정렬을 통해 답을 도출한다.

<br>

# 핵심 아이디어

- 데드라인을 기준으로 배열을 정렬한다
- 데드라인이 제일 먼 날을 시작으로 현재 과제 기준 최소 마감 일자를 구한다 
    `day = Math.min(day, task[i][1])`
- `day`에 최소 마감 일자에서 해당 과제를 끝내는 데 걸리는 일수를 뺀다.

<br>

# 시간복잡도

```
O(N * logN)
```

<br>

# 어려웠던 점

아이디어를 떠올리면 쉽게 풀 수 있을 문제였는데, 그 아이디어를 떠올리는 데에 시간이 오래 걸렸습니다.

<br>

# 배운 점

내림차순 정렬법을 외우자.
`Arrays.sort(task, (a, b) -> b[1] - a[1]);`
