# 접근 방법

너비우선탐색을 통해 거리두기를 실천한 맵인지 확인한다.

<br>

# 핵심 아이디어

- bfs 활용해 응시자가 앉아있는 자리(P)를 탐색한다.
- 현재 위치에서 상하좌우를 확인했을 때, 해당 위치가 'P'이면 맨해튼 거리를 준수하지 않은 것이기 때문에 `false` 리턴한다.
- 상하좌우를 확인했을 때 해당 위치가 'X'이면 파티션으로 막혀 있기 때문에 맨해튼 거리를 지키지 않아도 거리두기를 지킨 것임으로 `continue`
- 이외의 경우에는 탐색을 시도해야 함으로 q에 저장한다.

- bfs 결과가 false일 경우 `answer` 배열에 0을, true면 1을 저장하여 결과를 리턴한다.
<br>

# 시간복잡도

```
O(N)
```
