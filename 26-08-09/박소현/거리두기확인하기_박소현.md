# 문제 접근 방식
- 앉아 있는 사람 기준으로 규칙 준수 확인
- (0,0)부터 최대한 중복되지 않게 판별

# 핵심 아이디어
- 좌측 상단부터 우측 하단으로 내려가면서 탐색
- 단계별 규칙 확인
   1. 우측 및 하단에 맨해튼 거리가 1인 사람 유무 => 있으면 반드시 0 리턴
   2. 우측 및 하단 직선으로 맨해튼 거리가 2인 사람 유무
      1. 있으면 사이에 파티션 유무 확인 => 없으면 반드시 0 리턴
   3. 하단 대각선으로 맨해튼 거리가 2인 사람 유무
      2. 있으면 양쪽으로 파티션 유무 확인 => 하나라도 없으면 반드시 0 리턴
# 복잡도
## 시간 복잡도
solution O(5) => 대기실 수 5 고정
- checkPlace O(5*5) => 대기실 크기 5X5 고정
   - checkDistancing O(6) => 연산 6번 고정
 O(5*5*5*6) => O(1)
## 공간 복잡도
answer O(5) => O(1)
