# 문제 접근 방식
- 내림차순 정렬해서 비교하기
- (i + 1)번째 과제의 마감일과 (i)번째 과제 시작일 전날을 비교해서 더 빠른 날을 저장

# 핵심 아이디어
정렬 시 기준을 마감일 기준으로 하기

# 복잡도
## 시간 복잡도
O(T*NlogN) => 정렬 시, NlogN(T: 테스트 케이스 수, N 과제 수)
## 공간 복잡도
O(N)

# 풀이하면서 실수했던 부분
각각의 날짜가 어떤 의미를 갖는지 이해하는데 시간이 걸렸다.

# 다시 푼다면 개선하고 싶은 점
