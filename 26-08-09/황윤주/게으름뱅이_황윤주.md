# 접근 방법

- 과제를 **마감일 기준 내림차순 정렬**한 뒤, 가장 늦은 마감일부터 거꾸로 시간을 계산하는 그리디 방식을 사용하였다.

<br>

# 핵심 아이디어
1. 마감일 기준 내림차순 정렬
2. 차례대로 빼면서 계산하기
3. Math.min()을 사용하는 이유
- 현재 계산된 시간보다 과제의 마감일이 더 빠를 수 있다.
- 이 경우 해당 과제의 마감일 이전에 작업을 끝내야 하므로 더 작은 값으로 갱신해야 한다.


<br>

# 시간복잡도

```
O(N log N)
```
