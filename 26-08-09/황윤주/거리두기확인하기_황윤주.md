# 접근 방법
- 각 사람(P)을 기준으로 거리 2 이내에 다른 사람이 존재하는지 확인
- 처음에는 모든 사람의 위치를 저장한 후 맨해튼 거리를 계산하는 방법을 생각했지만, 파티션(X)의 존재 여부까지 고려해야 했다.
- 따라서 사람(P)을 발견할 때마다 BFS를 수행하여 거리 2 이내에서 이동 가능한 위치를 탐색하는 방법을 선택했다.



<br>

# 핵심 아이디어

- 모든 사람을 찾아 해당 사람 기준으로 BFS 수행 
- 거리 정보를 함께 저장하여 현재 위치가 시적점으로부터 얼마나 떨어져 있는지 확인
- 거리 2까지만 탐색
- 파티션은 해당 위치로 이동못하게 막음 (벽이라 생각)
- 거리 2 이내에서 P 발견하면 실패 


<br>

# 시간복잡도

대기실의 크기가 5x5로 고정되어 있으므로
모든 탐색 횟수는 상수 범위 내에서 수행된다.



```
O(1)
```

<br>

# 어려웠던 점

BFS를 어디서 시작해야 하는지 헷갈렸다.
처음에는 빈 자리에서 탐색해야 하는지 고민했지만
사람 주변에 거리 2 이내의 다른 사람이 존재하는가를 확인해야
하는 것이므로 P에서 BFS를 시작했다 

<br>

# 배운 점
- 거리 제한이 있는 탐색 문제는 BFS로 해결할 수 있다
- 파티션을 벽처럼 처리하는 방식
