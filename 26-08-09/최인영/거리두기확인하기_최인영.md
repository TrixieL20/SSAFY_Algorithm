## 1️⃣ 문제 접근 방식
#### 📌 사용 알고리즘 - BFS

맨해튼 거리 2 이내란 제약 두되, BFS로 탐색하며 경로 상에서 문제 조건대로 거리 두기 지켜졌는지 여부를 확인했음.

## 2️⃣ 핵심 아이디어
🌟 5 x 5 대기실 내 지점마다 해당 지점에서 시작하는 BFS 사용해 거리두기 여부 검사. 이때 queue에 column과 row 말고도 거리 함께 저장해 맨해튼 거리 2 이내인 지점만 탐색하도록 함

🌟 BFS 중 다음 이동 지점이 파티션 X인 경우 거리 2 이동하면서 파티션 거친 것이므로 다른 검사할 필요 x -> 거리두기 준수한 것이므로 true 처리

🌟 BFS 중 파티션 X 거치지 않고 P 만나는 경로는 거리두기 수칙 준수하지 않은 것이므로 false 처리 

---
✏️ 풀이 과정

1️⃣ 대기실마다 대기실 전체가 거리두기 수칙 준수했는지 확인해 주는 함수 isQuarantined 수행 -> 결과를 answer에 담음 
2️⃣ isQuarantined 에서는 대기실 내부 지점마다 맨해튼 거리 2 이내의 지점에 대해 너비 우선 탐색 시행하며 경로 파악해 거리 두기 여부 확인해 줄 bfs 함수 호출 
   
    ↪️ 한 지점이라도 bfs 함수 return 값이 false(거리두기 미준수)인 경우 다른 지점은 검사할 필요 없이 false
    
3️⃣ bfs 에서는 한 지점에서 출발해 bfs 수행하며 경로 따라가며 거리두기 여부 검사
    ↪️ queue에 row와 col 정보 외에도 출발지점에서 해당지점까지의 이동 거리 함께 저장해 그 값이 2가 되는 순간 더는 queue에 다음 지점 추가하지 않고 탐색 마무리.
    ↪️ queue가 빌 때까지
        ↪️ 상하좌우 이동방향마다 다음 이동 지점 설정 -> 배열 범위 벗어나거나 이미 방문한 곳인 경우 continue
        ↪️ 다음 지점이 파티션 X인 경우 이동 경로 안에 파티션이 있는 것이므로 다음 지점이 P여도 거리 두기 준수한 것 -> continue 
        ↪️ 파티션 X 거치지 않았으나 다음 지점이 P인 경우 거리두기 수칙 준수하지 않은 것이므로 return false
        ↪️ 다음 지점이 빈 테이블 O였던 경우 다음 이동 경로 확인하기 위해 queue에 넣고 방문 처리
   
## 3️⃣ 시간복잡도
`대기실 하나당 5×5로 고정이므로 상수 범위`
