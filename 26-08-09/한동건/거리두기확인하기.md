# 접근 방법
요소가 'P'인 칸 기준으로 맨해튼거리가 2이내에 'P'가 있는 경우에 거리두기가 돼었는지 확인 방법으로 접근했습니다.

<br>

# 핵심 아이디어

String을 char배열에 두어서 하나의 char씩 탐색하여 거리두기 기준을 확인한다.

<br>

# 시간복잡도

O(N^2)

<br>

# 어려웠던 점 / 배운점

입력이 String[][]으로 들어왓었는데 자바의 String은 인덱스로 접근이 안되는것을 몰랐어서 애를먹었다.

접근하기 위해 String을 str.toCharArray();로 바꿔서 격자하나씩 접근하였다
