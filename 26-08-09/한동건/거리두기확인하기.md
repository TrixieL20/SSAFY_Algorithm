# 문제 정보

프로그래머스 / Lv2 / 여행경로

<br>

# 접근 방법
요소가 'P'인 칸 기준으로 맨해튼거리가 2이내에 'P'가 있는 경우에 거리두기가 돼었는지 확인 방법으로 접근했습니다.

<br>

# 핵심 아이디어

한칸씩 거리두기 기준을 확인한다.

<br>

# 시간복잡도

O(N^2)

<br>

# 어려웠던 점

입력이 String[][]으로 들어왓었는데 자바의 String은 인덱스로 접근이 안되는것을 몰랐어서 애를먹었다.

String을 str.toCharArray();로 바꿔서 격자하나씩 접근하였다

<br>

# 배운 점

자바 String은 인덱스접근이 안된다
