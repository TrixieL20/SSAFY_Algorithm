# 문제 정보

| 항목 | 내용 |
| ----- | ------ |
| 문제 이름 | 차량 정비소 |
| 난이도 | 모의 SW 역량테스트  |
| 플랫폼 | SWEA |


## 접근 방법

- 시간이 0부터 1씩 증가하는 시뮬레이션으로 구현한다.
- 각 창구에 현재 이용 중인 고객번호와 업무 종료 시각을 저장한다. 고객번호가 0이면 빈 창구이다.
- 접수 대기열과 정비 대기열은 각각 FIFO 큐로 관리하고, 고객마다 이용한 접수 창구번호를 기록한다.
- 매 시각 다음 순서로 처리한다.
  1. 현재 시각에 도착한 고객을 고객번호 순서대로 접수 대기열에 넣는다.
  2. 정비가 끝난 창구를 비운다.
  3. 접수가 끝난 고객을 **접수 창구번호 오름차순**으로 정비 대기열에 넣고 접수 창구를 비운다.
  4. 빈 접수 창구를 번호가 작은 순서대로 확인하면서 접수 대기 고객을 배정한다.
  5. 빈 정비 창구를 번호가 작은 순서대로 확인하면서 정비 대기 고객을 배정한다.
- 정비 창구에 배정할 때, 이용했던 접수 창구가 A이고 배정받는 정비 창구가 B이면 고객번호를 정답에 더한다.
- 모든 고객이 정비 창구에 배정되면 종료한다. 이후 정비가 끝나더라도 이용 창구는 바뀌지 않으므로 실제 완료까지 기다릴 필요가 없다.

## 핵심 아이디어

- **접수 대기 순서는 고객번호 순서이다.** 고객번호는 도착 순서대로 주어지므로, 입력 순서대로 도착한 고객을 큐에 넣으면 된다. 도착 시각이 같아도 고객번호가 작은 고객부터 들어간다.
- **정비 대기 순서는 접수 완료 시각 → 이용한 접수 창구번호 순서이다.** 시간을 오름차순으로 진행하고, 같은 시각에 완료한 고객은 접수 창구번호 순으로 큐에 넣으면 이 조건을 만족한다. 이전 시각부터 기다리던 고객은 큐 앞쪽에 그대로 남는다.
- **같은 시각의 완료 처리를 모두 끝낸 뒤 배정한다.** 이동 시간이 0이므로 시각 t에 접수가 끝난 고객은 시각 t에 정비를 시작할 수 있다. 시각 t에 업무가 끝난 창구에도 바로 다음 고객을 배정할 수 있다.
- **빈 창구도 번호순으로 확인한다.** 큐의 맨 앞 고객을 가장 작은 빈 창구에 배정하므로 창구 선택 우선순위까지 만족한다.
- 시각 t에 처리 시간이 d인 창구로 들어가면 종료 시각은 `t + d`이다. 처리 시간이 모두 1 이상이므로 같은 시각에 새로 배정한 고객이 바로 완료되는 경우는 없다.

## 시간복잡도

- 시간복잡도: **O(K + L × (N + M))**
  - L은 마지막 고객이 정비 창구에 배정되는 시각이다. 각 시각에 모든 접수·정비 창구를 순회하고, 각 고객은 두 큐에 한 번씩 들어가고 나온다.
  - 최대 도착 시각을 T, 최대 접수 시간을 a_max, 최대 정비 시간을 b_max라고 하면 `L ≤ T + K × a_max + K × b_max`라는 보수적인 상한을 사용할 수 있다.
  - 주어진 제약에서 이 상한은 `1,000 + 1,000 × 20 + 1,000 × 20 = 41,000`이므로 충분히 처리할 수 있다.

- 공간복잡도: **O(K + N + M)**
  - 고객의 도착 시각, 이용한 접수 창구, 대기열에 O(K), 창구 상태에 O(N + M)이 필요하다.
