# 접근 방법 / 핵심 아이디어

while문 안에서 time++으로 시간경과를 시키면서 시뮬레이션을 돌렸다.

접수와 정비가 끝난 고객 처리 -> 도착 처리 -> 창구 배정 처리 하였다



<br>

# 시간복잡도
- 최대 시각 T_max ≈ 1000(도착) + 1000×20(접수) + 1000×20(정비) ≈ 41,000
- 매 시각 창구 순회 O(N + M), 도착 처리는 `time <= maxVisit`일 때만 O(K)
- **O(T_max × (N+M) + maxVisit × K)** ≈ 41,000×18 + 1,000×1,000 ≈ 1.7×10⁶ → 여유 있게 통과
- 공간: O(N + M + K)
