# 접근 방법 / 핵심 아이디어
각 구간의 끝 지점이 작은 순으로 정렬 한 뒤에 , 가장 작은 끝 지점 부터 순서대로 카메라를 둘 때 몇 개의 구간까지 커버되는지 판단하여 카메라를 둘 수를 구한다.

정렬한 뒤에, 모든 구간을 탐색 할 바깥 while문과 안쪽의 이번 구간의 끝 지점이 다음 구간들을 커버하는되는지 탐색하는 while 문을 써 구현하였음.



<br>

# 시간복잡도

정렬: O(N log N)
탐색: idx가 0 → N으로 단조 증가만 하므로 이중 while이어도 O(N)
전체: O(N log N), N ≤ 10,000 → 약 1.3×10⁵ 연산
공간: O(1) (정렬 내부 공간 제외)
