# 문제 정보

| 항목 | 내용 |
|---|---|
| 문제 이름 | 단속카메라 |
| 난이도 | Lv3 |
| 플랫폼 | 프로그래머스 |
| 사용 알고리즘 | 그리디 |

<br>

# 접근 방법

- 각 구간을 시작점(start) 기준으로 오름차순 정렬한 뒤, start <= end인지 확인해 현재 구간과 겹치는지 판단했다.

<br>




<br>

# 핵심 아이디어

- `routes[i][0]` 을 기준으로 오름차순 정렬해 시작점이 작은 구간부터 확인했다.
- 새 구간의 시작점이 현재 구간의 끝점 이하라면, 두 끝점 중 더 작은 값으로 end를 갱신했다.
- 새 구간의 시작점이 현재 구간의 끝점을 넘어가면, count를 증가시켜 카메라를 한 대 추가했다.
- 마지막 구간에 필요한 카메라가 집계에서 빠지지 않도록 count를 1로 초기화했다.


<br>

# 시간복잡도

**O(N log N)**

- N : 차량 경로의 개수

<br>

# 배운 점

- 구간을 다룰 때 인덱스 범위를 설정하는 부분이 헷갈렸다. 비슷한 문제를 더 풀어보며 익숙해져야겠다.

<br>

# 실수한 부분

- 처음에는 end를 갱신하지 않아 올바른 결과가 나오지 않았다.
