# 접근 방법
- 한 번의 교환에서 가능한 모든 두 자리 조합을 확인한다.
- 숫자를 교환한 뒤 DFS를 호출하여 다음 교환을 진행한다.
- DFS 탐색이 끝나면 다시 두 숫자를 교환하여 원래 상태로 복구한다.
- 정해진 교환 횟수에 도달하면 현재 숫자를 정수로 변환하여 최댓값을 갱신한다.
- 같은 교환 횟수에서 동일한 숫자 상태가 다시 등장할 수 있으므로 방문 여부를 확인하여 중복 탐색을 줄인다.

## 자료구조
- `char[]` : 숫자의 각 자릿수를 저장하고 두 자리의 위치를 쉽게 교환하기 위해 사용
- `HashSet<String>[]` : 각 교환 횟수에서 이미 탐색한 숫자 상태를 저장하여 중복 탐색 방지

<br>

# 핵심 아이디어

* 모든 두 자리의 조합을 선택하여 교환하는 완전탐색 문제이다.
* 숫자를 교환한 뒤 재귀 호출하고, 탐색이 끝나면 다시 교환하여 원상복구하는 백트래킹을 사용한다.
* DFS의 깊이를 현재까지 수행한 교환 횟수로 사용한다.

<br>

# 시간복잡도
O((L²)^K)
- L : 숫자의 길이
- K : 교환 횟수

# 배운 점
- DFS에서 배열의 상태를 직접 변경했다면 재귀 호출이 끝난 후 반드시 원래 상태로 복구해야 한다.
