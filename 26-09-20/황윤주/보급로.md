# 접근 방법
- 시작점 `(0, 0)`에서 도착점 `(N-1, N-1)`까지 이동하면서 복구 시간의 최솟값을 구한다.
- 각 칸마다 복구 비용이 다르기 때문에 단순 BFS가 아닌 다익스트라 알고리즘을 사용한다.
- `dist[r][c]`에 시작점부터 해당 위치까지 이동하는 데 필요한 최소 복구 시간을 저장한다.
- PriorityQueue를 사용하여 현재까지의 누적 비용이 가장 작은 위치부터 탐색한다.
- 상하좌우로 이동하면서 새로운 경로의 비용이 기존 최소 비용보다 작으면 `dist`를 갱신하고 PriorityQueue에 추가한다.

## 자료구조
- `int[][] map` : 각 위치의 복구 비용 저장
- `int[][] dist` : 시작점부터 각 위치까지의 최소 누적 비용 저장
- `PriorityQueue<Node>` : 현재까지의 누적 비용이 작은 위치부터 탐색하기 위해 사용
- `Node` : 행, 열, 현재까지의 누적 비용을 저장

<br>

# 핵심 아이디어

* 각 칸까지 도달하는 데 필요한 최소 누적 비용을 계속 갱신한다.
* 다음 위치까지의 비용은 `현재까지의 비용 + 다음 칸의 복구 비용`으로 계산한다.

<br>

# 시간복잡도
O(N² log N²)

# 배운 점
- 격자에서 상하좌우로 이동하더라도 각 칸의 이동 비용이 다르면 단순 BFS가 아닌 다익스트라를 고려해야 한다.
- 다익스트라는 현재까지 발견한 경로 중 누적 비용이 가장 작은 위치부터 탐색한다.
- PriorityQueue와 Comparable을 이용하면 누적 비용이 작은 Node부터 꺼낼 수 있다.

# 실수한 부분
- 일반 BFS처럼 visited[][]를 사용해 한 번 방문한 위치를 다시 방문하지 않도록 하면 더 저렴한 경로를 놓칠 수 있다.
- map[nr][nc] 자체가 아니라 현재까지의 누적 비용 + map[nr][nc]를 비교해야 한다.
