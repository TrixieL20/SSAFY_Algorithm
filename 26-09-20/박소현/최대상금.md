# 문제 접근 방식
DFS를 활용한 조합으로 풀기

# 핵심 아이디어
- 두 개의 자리를 정해서 교환하는 방식으로 풀기
- 2차원 방문 배열(isVisited)을 활용해, 동일한 횟수를 남기고, 똑같은 숫자를 만든 이력이 있으면 탐색 중단

# 복잡도
## 시간 복잡도
O(V*C) => V: 생성 가능한 숫자의 최대 가짓수, C: 교환 횟수)
- 방문 처리 하지 않았을 때, 한 턴에 15번(6C2)의 교환으로 O(15^C)가 된다.
   => 방문 처리를 해서, 최악의 경우에도 최대 숫자(999999)*교환횟수(최대 10) 이내의 연산 수행 
## 공간 복잡도
O(M * C) => M: 가능한 숫자의 최댓값, C: 교환 횟수
- 2차원 방문배열 isVisited: O(1000000*12)

# 풀이하면서 실수했던 부분
- 처음에는 문제를 잘못 이해해서 i랑 j랑 같을 때도 되게 했다. 또한 isVisited 배열로 방문 처리를 하지 않아, 무한루프 발생
   => 문제를 잘 읽고, DFS에서는 방문처리가 왠만해서는 필요하다는 것을 명심하자.
- 교환을 줄이려고 start 변수를 받아서 start랑 다른 한 자리랑 교환하게 했다. 그렇게 하니 반드시, 맨 앞부터 교환하는 결과가 발생했다.
 => 조합의 의미를 잘 생각해서 문제를 풀자.
