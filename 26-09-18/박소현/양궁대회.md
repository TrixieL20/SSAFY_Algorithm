# 문제 접근 방식
조합으로 풀자.

# 핵심 아이디어
1. 재귀로 조합 만들기
2. 가지치기 하기
   1. 어피치 점수 계산 후, 28점 이상이면 라이언이 못 이기므로 return
   2. 어피치 화살보다 남은 화살이 적은 경우, 그 과녁에 안 쏘고 넘어가기
3. 같은 점수 차가 나면 제일 적은 점수의 화살이 많은 경우를 리턴해야 하므로, 화살이 마지막에 남으면 전부 0점 과녁에 쏘기

# 복잡도
## 시간 복잡도
O(2^11)
- 재귀 호출 깊이 최대 11
## 공간 복잡도
O(1)
# 풀이하면서 실수했던 부분
- 처음에 diff가 0 이상일 때, maxDiff랑 비교해야 하는데, 그거 안 해줘서 maxDiff가 -1이고 diff가 -1일 때도 answer에 배열이 들어감
- 그 밖에도 상황 별로 if문을 만들어서 다양한 버그들이 나타났는데, gemini의 도움을 받아 처리했다.
  - 로직을 최대한 단순하게 짤 수 있도록 노력해야겠다.
- 사실 처음에 로직 짤 때 시간 복잡도 최대 11^11로 나오는 줄 알고, 시간 초과를 예상하고 있었다. 하지만 아니었다. 시간 복잡도 계산을 좀 더 정확하게 해야할 필요가 있다.
