# 문제 접근 방식
부분집합 만들어서 풀자.

# 핵심 아이디어
1. Next Permutation으로 조합을 구성
2. dfs로 조합
# 복잡도
## 시간 복잡도
### Next Permutation
O(N * 2^N)
- while문: O(2^N) => 조합 만드는 거라 while문 다 돌면 2^N - 1
  - for문: O(N)
### DFS
O(2^N)
## 공간 복잡도
### Next Permutation
O(N)
- scores 배열: O(N)
- calories 배열 : O(N)
- combi 배열: O(N)
### DFS
O(N)

# 풀이하면서 실수했던 부분
## Next Permutation
- 테스트 케이스가 1개 밖에 주어지지 않아서 2개 이상일 때는 확인 안 해보고 그냥 제출했다가 answer 초기화 안 해줘서 틀렸다.
  - 제출 전에 테스트 케이스 여러 개 만들어서 돌려보기
- next permutation으로 조합을 만들 때, 조합 배열 새로 만들지 않으려고 초기화 방법을 바꿨다가 정렬이 안 되어 있어서 계속 답이 이상하게 나왔다.
  - next permutation 쓸 때, 배열이 어떻게 되고 있는지 찍어보고 확인하기
- 생각보다 시간이 오래 걸리는 풀이라, dfs로도 풀어봐야겠다.
## DFS
- Next Permutation으로 풀던 게 남아있어서 dfs로 구현했을 때, for문으로 탐색할 갯수 지정 후 탐색할 갯수만큼 DFS 돌게 했더니 오히려 탐색횟수가 계속 늘어나 시간초과가 났다. dfs로도 자주 풀면서 어떤 식으로 푸는 건지 계속 익혀둬야겠다.
- dfs는 탐색할 때, 순서대로 인덱스들을 방문하면서 선택할지 말지 결정하는건데 dfs 내에서도 for문으로 모든 인덱스들에 대해서 방문 처리를 해서 시간초과가 났다. dfs가 어떤 식으로 조합이 되는 건지 잘 생각하면서 풀어야겠다.
