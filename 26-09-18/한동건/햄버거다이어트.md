# 접근 방법 / 핵심 아이디어


각 재료를 포함/미포함하는 완전탐색(부분집합 DFS, 2^N)에 칼로리 초과 가지치기를 결합.
- idx번째 재료를 넣을지 말지 두 갈래로 재귀(dfs(idx+1, ...) 두 번 호출)해서 모든 2^N 조합을 순회
- totalCal > L이 되는 순간 즉시 return해서 그 아래 서브트리를 통째로 잘라냄(pruning)
- N ≤ 20 (SWEA 제약) → 최악 2^20 ≈ 100만 노드라 완전탐색으로 충분히 통과 가능

처음 문제를 본 순간 모든 부분집합을 만들어보고 제한 칼로리를 넘으면 리턴하자는 접근을 했다.
그 후 N이 최대 20으로 2^20을 해도 100만개 경우의수 이므로 접근을 진행했다.
<br>

# 시간복잡도

- 시간: O(2^N) per 테스트케이스, 전체 O(T · 2^N). 가지치기가 있어도 최악의 경우(모든 조합이 L 이내) 점근적으로는 그대로 O(2^N)
- N=20 기준 2^20=1,048,576 → 연산량 자체는 1초 컷 가능한 수준, 실제로는 칼로리 초과 조기 컷으로 훨씬 적은 노드만 방문
- 공간: O(N) — 재귀 깊이 N + scores/cals 배열
