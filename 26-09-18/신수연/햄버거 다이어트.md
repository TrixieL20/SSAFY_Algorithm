# 접근 방법

각 재료를 선택하는 경우와 선택하지 않는 경우를 조합 형태의 DFS로 탐색한다.

음식을 선택할 때마다 현재까지의 점수와 칼로리를 갱신하고, 칼로리 제한을 초과하지 않는 경우에만 다음 재료를 선택한다.

`start` 인덱스를 사용하여 이미 확인한 재료를 다시 선택하지 않도록 함으로써 동일한 재료 조합을 순서만 다르게 탐색하는 중복을 제거한다.

<br> 

# 핵심 아이디어

### 1. 조합 형태의 DFS

`visited` 배열을 사용하는 대신 `start`를 전달한다.

```java
for (int i = start; i < n; i++) {
    ...
    dfs(i + 1, ...);
}
```

예를 들어 `A → B`를 선택한 경우 `B → A`는 탐색하지 않는다.
두 경우 모두 같은 재료 조합이기 때문에 한 번만 탐색하면 된다.

### 2. 칼로리 제한 확인

재료를 선택하기 전에 현재 칼로리와 해당 재료의 칼로리를 더했을 때 제한을 초과하는지 확인한다.

```java
if (calorie + info[i][1] > l) {
    continue;
}
```

제한을 초과하는 경우 해당 재료를 선택하지 않고 다음 재료를 확인한다.

### 3. 최대 점수 갱신

DFS에 진입할 때마다 현재까지 선택한 재료들의 점수를 기준으로 최대 점수를 갱신한다.

```java
maxScore = Math.max(maxScore, score);
```

따라서 정확히 칼로리 제한까지 사용하지 않더라도 현재까지의 조합 중 가장 높은 점수를 저장할 수 있다.

<br> 

# 시간복잡도

* 시간복잡도: O(2^N)
* 공간복잡도: O(N)

각 재료마다 선택하거나 선택하지 않는 두 가지 경우가 존재하므로 최대 `2^N`개의 조합을 탐색한다.

DFS의 최대 깊이는 `N`이므로 재귀 호출에 필요한 공간복잡도는 O(N)이다.
