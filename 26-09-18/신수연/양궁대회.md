# 접근 방법

라이언이 10점부터 0점까지 각 점수를 가져갈지 포기할지를 DFS로 탐색한다.

각 점수에서 라이언이 해당 점수를 얻으려면 어피치가 해당 점수에 쏜 화살보다 1발 더 많이 쏴야 한다.

* 라이언이 해당 점수를 가져가는 경우

  * `info[score] + 1`개의 화살을 사용한다.
  * 라이언의 점수에 해당 점수를 더한다.
* 라이언이 해당 점수를 포기하는 경우

  * 어피치가 해당 점수에 화살을 쐈다면 어피치의 점수에 해당 점수를 더한다.
  * 어피치가 0발을 쐈다면 아무도 점수를 얻지 못한다.

11개의 점수에 대한 선택이 끝나면 남은 화살은 모두 0점에 사용한다.

모든 경우를 탐색한 후 라이언과 어피치의 점수 차이가 가장 큰 경우를 정답으로 선택한다.

점수 차이가 같은 경우에는 낮은 점수에 더 많은 화살을 쏜 경우를 우선하여 정답을 갱신한다.

<br>

# 핵심 아이디어

### 1. DFS를 이용한 경우의 수 탐색

각 점수마다 라이언이 해당 점수를 가져갈지 포기할지를 결정한다.

```text
10점 → 가져가기 / 포기
9점  → 가져가기 / 포기
8점  → 가져가기 / 포기
...
0점  → 가져가기 / 포기
```

따라서 최대 `2^11`개의 경우를 탐색할 수 있다.

### 2. 점수를 얻기 위한 화살 수

라이언이 특정 점수를 가져가기 위해서는 어피치보다 1발 더 많이 쏴야 한다.

```java
int required = info[score] + 1;
```

남은 화살이 `required` 이상인 경우에만 해당 점수를 가져가는 DFS를 수행한다.

### 3. 남은 화살은 0점에 사용

모든 점수에 대한 선택이 끝났을 때 남은 화살은 0점에 모두 사용한다.

```java
ryan[10] += arrows;
```

0점은 승패에 영향을 주지 않기 때문에 남은 화살을 모두 배치해도 점수에는 영향을 주지 않는다.

### 4. 최대 점수 차이 갱신

모든 점수에 대한 선택이 끝나면 라이언과 어피치의 점수 차이를 계산한다.

```java
int diff = ryanScore - apeachScore;
```

라이언의 점수가 더 높고 현재까지의 최대 점수 차이보다 크다면 정답을 갱신한다.

점수 차이가 같은 경우에는 낮은 점수부터 비교하여 해당 점수에 더 많은 화살을 쏜 경우를 선택한다.

<br>

# 시간복잡도

* 시간복잡도: `O(2^11)` → 각 점수마다 2가지 선택을 하므로 최대 2048개의 경우를 탐색
* 공간복잡도: `O(11)` → DFS의 최대 깊이와 라이언의 화살 배치 배열에 사용되는 공간
