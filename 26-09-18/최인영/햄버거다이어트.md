## 1️⃣ 문제 접근 방식
#### 📌 사용 알고리즘 - DFS + 백트래킹

각 재료마다 **선택하는 경우 / 선택하지 않는 경우** 두 가지로 나눠 DFS 탐색했음 !

단, 재료를 선택했을 때 총 칼로리가 제한 `L`을 넘는 경우는 탐색하지 않도록 처리.

## 2️⃣ 핵심 아이디어

🌟 각 재료마다 선택 / 미선택 두 경우 탐색

🌟 선택했을 때 누적 칼로리가 제한 이하인 경우에만 DFS 진행

🌟 모든 재료를 확인한 경우 현재 맛 점수와 `maxScore` 비교해서 최댓값 갱신

---

✏️ 풀이 과정

1️⃣ 재료의 맛 점수와 칼로리를 `ingredients`에 저장

2️⃣ `dfs(index, calories, scores)`로 현재 재료를 선택하지 않는 경우 먼저 탐색

3️⃣ 현재 재료를 추가해도 제한 칼로리를 넘지 않으면 선택하는 경우도 탐색

4️⃣ `index == n`이면 모든 재료를 확인한 것이므로 `maxScore` 갱신

## 3️⃣ 시간복잡도
`O(2^n)`

각 재료마다 선택 / 미선택 두 경우를 탐색 !

## 4️⃣ 풀이하면서 실수했던 부분
재료를 선택하는 경우 **누적 칼로리가 제한을 넘지 않는지 먼저 확인해야 함 !**

## 5️⃣ 다시 푼다면 개선하고 싶은 점
부분집합 문제라는 걸 바로 떠올리면 DFS로 비슷하게 풀 수 있을 듯 !
