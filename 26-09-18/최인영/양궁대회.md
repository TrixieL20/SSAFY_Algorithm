## 1️⃣ 문제 접근 방식

#### 📌 사용 알고리즘 - DFS + 백트래킹

각 점수마다 라이언이 **어피치보다 한 발 더 쏴서 점수를 가져갈지 / 아예 포기할지** 두 경우로 나눠 DFS 탐색했음 !

## 2️⃣ 핵심 아이디어

🌟 해당 점수를 가져가려면 `info[index] + 1`발 필요

🌟 점수를 가져가는 경우 / 포기하는 경우 두 갈래로 DFS 진행

🌟 모든 점수 탐색 후 라이언과 어피치의 점수 차 계산

🌟 점수 차가 같다면 문제 조건대로 **낮은 점수를 더 많이 맞힌 경우** 선택

---

✏️ 풀이 과정

1️⃣ 10점부터 0점까지 DFS 탐색

2️⃣ 남은 화살이 충분하면 `어피치 화살 수 + 1`만큼 사용해서 해당 점수 획득

3️⃣ 해당 점수를 포기하는 경우도 DFS 진행

4️⃣ 모든 점수를 확인한 뒤 남은 화살은 0점에 몰아줌

5️⃣ 라이언과 어피치 점수 차가 기존 최대보다 크면 `answer` 갱신

6️⃣ 점수 차가 같다면 0점부터 역순으로 비교해서 낮은 점수를 더 많이 맞힌 경우 선택

## 3️⃣ 시간복잡도

`O(2¹¹)`

각 점수마다 획득 / 포기 두 경우를 탐색 !

## 4️⃣ 풀이하면서 실수했던 부분

최대 점수 차만 비교하면 안 되고, **점수 차가 같은 경우 낮은 점수를 더 많이 맞힌 배열을 선택해야 하는 조건**도 따로 처리해야 했음 !

## 5️⃣ 다시 푼다면 개선하고 싶은 점

DFS에서 각 점수마다 **가져간다 / 포기한다** 두 경우로 나눈다는 것만 떠올리면 비슷하게 풀 수 있을 듯 !
