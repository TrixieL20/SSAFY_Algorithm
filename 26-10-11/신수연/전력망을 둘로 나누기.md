# 문제 정보

| 항목    | 내용          |
| ----- | ----------- |
| 문제 이름 | 전력망을 둘로 나누기    |
| 난이도   | Level 2     |
| 플랫폼   | Programmers |

<br>

# 접근 방법

- 연결된 간선을 끊은 후 bfs 탐색을 하여 연결된 노드의 수를 구한다.
- bfs 탐색 후 리턴된 노드의 수 `result`를 통해 두 전력망이 가진 송전탑 개수를 비교한다.
- 탐색이 끝나면 끊었던 간선을 다시 연결한다.
- 해당 과정을 반복해 송전탑 개수 차이의 최솟값을 구한다.
<br>

# 핵심 아이디어

- 연결된 간선을 하나씩 끊어 bfs 탐색을 진행한다.


# 시간복잡도

- 시간 복잡도: O(n^2)
- 공간 복잡도: O(n^2)
