# 문제 정보

| 항목    | 내용      |
| ----- |---------|
| 문제 이름 | Ladder1 |
| 난이도   | D4      |
| 플랫폼   | SWEA    |

<br>

# 접근 방법
- 사다리의 도착점인 `2`의 위치를 먼저 찾아 시작점으로 설정한다.
- 도착점에서 출발하여 아래에서 위로 사다리를 역추적한다.
- `Queue`를 이용한 BFS 방식으로 현재 위치에서 이동 가능한 다음 위치를 탐색한다.
- 사다리를 역으로 올라갈 때는 `왼쪽 → 오른쪽 → 위쪽` 순서로 확인한다.
- 왼쪽이나 오른쪽으로 이동할 수 있다면 해당 방향으로 이동하고, 좌우로 이동할 수 없는 경우 위쪽으로 이동한다.
- 이미 지나온 사다리로 다시 돌아가지 않도록 `visited` 배열을 사용한다.
- `x == 0`이 되면 사다리의 맨 위에 도착한 것이므로 현재 열 `y`를 정답으로 저장한다.

## 자료구조
- `int[][] ladder` : 사다리 정보를 저장
- `boolean[][] visited` : 이미 지나간 위치인지 확인
- `Queue<int[]> queue` : 다음에 이동할 위치를 저장
- `fx`, `fy` : 값이 `2`인 도착점의 좌표
- `answer` : 도착점 `2`와 연결된 시작점의 열 번호

<br>

# 핵심 아이디어

* 도착점 `2`는 하나이므로 아래에서 위로 이동하면 시작점을 찾을 수 있다.
* 사다리에서는 좌우 이동이 가능한 경우 위로 바로 이동하면 안 되므로 `왼쪽 → 오른쪽 → 위쪽` 순서로 확인한다.
* `if - else if`를 사용하여 한 위치에서 하나의 방향으로만 이동하도록 한다.
* visited를 사용하지 않으면 좌우로 이동한 뒤 이전 위치로 다시 돌아갈 수 있으므로 방문 처리가 필요하다.
* 맨 위인 x == 0에 도착했을 때의 y가 찾고자 하는 출발점이다.

<br>

# 시간복잡도
O(N²)

# 배운 점
- 사다리 문제는 출발점에서 모든 경로를 확인하는 것보다 도착점이 하나라면 도착점에서 역으로 추적하는 방법을 사용할 수 있다.
- 이동 방향에 우선순위가 있는 경우 if - else if를 이용하여 한 번에 하나의 방향만 선택할 수 있다.
- visited 배열을 사용하면 이미 지나온 위치로 다시 이동하는 것을 방지할 수 있다.
- BFS는 최단거리 문제뿐만 아니라 Queue를 이용해 연결된 경로를 순서대로 탐색하는 데에도 사용할 수 있다.

# 실수한 부분
- 처음에는 현재 위치에서 가능한 모든 방향을 탐색하려고 했지만, 사다리에서는 좌우 이동이 가능하면 해당 방향을 먼저 따라가야 한다.
- 좌우 이동 후 이전 위치로 다시 돌아가는 것을 막기 위해 visited 처리가 필요하다.
- 출발점에서 시작하기보다 값이 2인 도착점에서 역으로 올라가면 하나의 경로만 추적하면 된다.
- 좌우 이동과 위쪽 이동을 각각 독립적인 if로 처리하면 여러 방향이 Queue에 들어갈 수 있으므로 if - else if로 처리해야 한다.
