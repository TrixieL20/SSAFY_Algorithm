# 접근 방법 / 핵심 아이디어
완전탐색(백트래킹)으로 접근했다. 각 막(행)마다 **투입 안 함 / A약품 / B약품** 3가지 중 하나를 고르는 경우의 수를 재귀로 만들었다.
모든 행의 선택이 끝나면(idx == D) 선택한 대로 약품을 투입하고, 각 열을 위에서부터 내려가며 같은 특성이 K개 이상 연속되는지 검사했다.
한 열이라도 K개를 넘지 못하면 실패, 모든 열이 통과하면 투입 횟수로 최솟값을 갱신했다.
검사가 끝나면 원본 배열(originalMatrix)로 복구해서 다음 경우의 수에 영향이 없게 했다.

가지치기 : 현재 경우의 투입 횟수가 이미 구한 최솟값 이상이면 성능 검사(isOkFilm)를 하지 않도록 했다.

<br>

# 시간복잡도
O(3^D × D × W)
D ≤ 13, W ≤ 20 이므로 3^13 ≈ 160만 개의 경우 × 검사 260번 → 최악 약 4억 번
가지치기로 실제 검사 횟수는 줄어들지만, 경우의 수 자체는 3^D개를 전부 끝까지 만든다.

<br>

# 어려웠던 점 / 배운점

약품을 투입하면 원본이 바뀌기 때문에, 매번 원본으로 복구하는 처리가 필요했다.

가지치기를 재귀의 끝(idx == D)에서만 하고 있어서, 투입 횟수가 이미 최솟값을 넘은 경우에도 끝까지 재귀를 내려간다.
투입 횟수를 재귀 인자로 넘기고 중간에 바로 return 하면 탐색 자체를 줄일 수 있을 것 같다.
또 답은 K를 넘을 수 없으므로(K개 행을 같은 약품으로 바꾸면 무조건 통과), 투입 횟수를 0개부터 늘려가며 처음 통과하는 순간 종료하는 방식이 더 빠를 것 같다.
