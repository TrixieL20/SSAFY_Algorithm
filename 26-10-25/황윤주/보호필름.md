# 접근 방법

- `D × W` 크기의 보호 필름에서 모든 열에 동일한 특성이 `K`개 이상 연속되어야 성능 검사를 통과한다.
- 각 행마다 약품을 투입하지 않거나, A 약품(0), B 약품(1)을 투입하는 3가지 선택이 가능하다.
- 따라서 DFS를 이용해 각 행의 변경 여부를 탐색하고, 성능 검사를 통과하는 최소 약품 투입 횟수를 구한다.
- 이미 구한 최소 투입 횟수 이상으로 약품을 사용한 경우에는 더 탐색하지 않는 가지치기를 적용한다.

<br>

## 자료구조

- `int[][] film` : 보호 필름의 특성 정보를 저장하는 2차원 배열
- `int D, W, K` : 필름의 두께(행), 가로 크기(열), 통과에 필요한 연속 개수
- `int answer` : 최소 약품 투입 횟수
- `int[] backup` : 약품 투입 전 행의 원본 데이터를 저장하는 배열
- `int row` : DFS에서 현재 탐색 중인 행
- `int count` : 현재까지 약품을 투입한 횟수

<br>

# 핵심 아이디어

- 각 행마다 **변경하지 않기 / A 투입 / B 투입**의 3가지 경우를 DFS로 탐색한다.
- 약품을 투입하면 해당 행의 모든 값을 0 또는 1로 변경한다.
- 모든 행에 대한 선택이 끝나면 `check()` 함수로 성능 검사 통과 여부를 확인한다.
- `check()`에서는 각 열을 위에서 아래로 순회하면서 동일한 값이 연속되는 개수를 계산한다.
- 하나의 열이라도 K개 이상 연속되는 구간이 없다면 성능 검사를 통과하지 못한다.
- 약품 투입 후에는 다른 경우를 탐색할 수 있도록 원래 행의 값을 복구해야 한다.
- 현재 투입 횟수가 이미 구한 최소 횟수 이상이라면 탐색을 중단한다.

### DFS 진행 과정

1. 현재 행을 변경하지 않고 다음 행 탐색
2. 현재 행의 원본 데이터를 `clone()`으로 저장
3. 현재 행 전체를 0으로 변경하고 다음 행 탐색
4. 현재 행 전체를 1로 변경하고 다음 행 탐색
5. 현재 행을 원상복구
6. 모든 행을 탐색했다면 `check()`로 통과 여부 확인
7. 통과했다면 최소 투입 횟수 갱신

<br>

# 시간복잡도

**O(3^D × D × W)**

- `D`는 필름의 행 개수, `W`는 열 개수이다.
- 각 행마다 3가지 선택이 가능하므로 최대 `3^D`개의 경우를 탐색한다.
- 한 번의 성능 검사에서 모든 열과 행을 확인하므로 `O(D × W)`가 필요하다.
- 따라서 전체 시간복잡도의 상한은 `O(3^D × D × W)`이다.
- 가지치기를 적용하면 실제 탐색 횟수를 줄일 수 있다.

**공간복잡도: O(D × W)**

- 보호 필름을 저장하는 2차원 배열이 필요하다.
- DFS 재귀 깊이는 최대 D이다.
- 각 재귀 단계에서 원본 행을 저장하는 배열을 사용한다.

<br>

# 배운 점

- DFS와 백트래킹을 활용하면 각 행에서 가능한 여러 선택을 탐색할 수 있다.
- 최소 횟수를 구하는 문제에서는 현재 결과가 이미 최솟값 이상인 경우 가지치기를 적용할 수 있다.
- 2차원 배열에서 행과 열의 역할을 정확하게 구분해야 한다.
- `Arrays.fill(film[row], 0)`을 사용하면 특정 행 전체를 동일한 값으로 변경할 수 있다.
- `film[row].clone()`으로 현재 행을 복사하여 원상복구에 활용할 수 있다.
- 연속된 값의 개수를 확인할 때는 이전 값과 현재 값을 비교하고, 값이 다르면 `count = 1`로 초기화한다.
- 모든 열이 성능 검사를 통과해야 하므로 하나의 열이라도 실패하면 `false`를 반환한다.

<br>

# 실수한 부분


### 1. 최소 투입 횟수를 0으로 초기화함

처음에는 다음과 같이 작성했다.

```java
answer = 0;
```

하지만 DFS 시작 부분에서 다음 조건으로 가지치기를 하고 있었다.

```java
if (count >= answer) return;
```

처음 호출할 때 `count = 0`, `answer = 0`이므로 DFS가 바로 종료된다.

따라서 최소 횟수를 구할 때는 충분히 큰 값으로 초기화해야 한다.

```java
answer = K;
```

연속된 K개 행을 모두 같은 값으로 변경하면 모든 열이 성능 검사를 통과하므로 최대 K번의 약품 투입으로 해결할 수 있다.



### 2. K가 1인 경우

K가 1이라면 모든 열에 이미 1개 이상의 값이 존재하므로 약품을 투입하지 않아도 통과한다.

```java
if (K == 1) return true;
```
