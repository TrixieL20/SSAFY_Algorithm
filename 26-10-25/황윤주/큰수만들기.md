# 문제 정보

| 항목 | 내용 |
|---|---|
| 문제 이름 | 큰 수 만들기 |
| 난이도 | Lv2 |
| 플랫폼 | 프로그래머스 |
| 사용 알고리즘 | 그리디, 스택 |

<br>

# 접근 방법

- 숫자 문자열 `number`에서 `k`개의 숫자를 제거하여 만들 수 있는 가장 큰 수를 구하는 문제이다.
- 큰 수를 만들기 위해서는 **앞자리에 가능한 한 큰 숫자가 위치해야 한다.**
- 따라서 앞자리 숫자가 뒷자리 숫자보다 작다면 앞자리 숫자를 제거하는 그리디 알고리즘을 사용한다.
- 처음에는 `StringBuilder`에서 `deleteCharAt(i)`로 문자를 직접 삭제하는 방식을 생각했다.
- 하지만 중간 문자를 삭제하면 뒤의 문자들이 앞으로 이동하고, 삭제가 반복되면 시간복잡도가 증가한다.
- 이를 개선하기 위해 `StringBuilder`를 스택처럼 활용하여 마지막 문자만 제거한다.



<br>

## 자료구조

- `StringBuilder sb` : String 삭제가 간편하여서 선택


<br>

# 핵심 아이디어

- 큰 수를 만들려면 앞쪽 자릿수에 큰 숫자가 위치해야 한다.
- StringBuilder에서 삭제할 때 인덱스 값이 변할 수 있으므로 삭제하고 나서 i--를 해줘야 한다
- 다 삭제하고 나서도 count값이 남아있다면 맨 뒤에서부터 하나씩 제거한다 


<br>

# 시간복잡도

**O(N)**

- `N`은 숫자 문자열의 길이이다.
- 각 문자는 한 번씩 `StringBuilder`에 추가된다.
- 각 문자는 최대 한 번만 삭제된다.
- 마지막 문자에 대한 추가 및 삭제는 상수 시간으로 처리할 수 있다.
- 따라서 전체 시간복잡도는 `O(N)`이다.

**공간복잡도: O(N)**

- 최대 `N`개의 문자를 저장하는 `StringBuilder`를 사용한다.

<br>

# 배운 점

- `StringBuilder`는 `append()`와 `deleteCharAt()`을 활용하여 삽입, 삭제 할 수 있다.
- 문자열의 중간 문자를 직접 삭제하는 것보다 마지막 문자만 삭제하는 방식이 효율적이다.
- 숫자 문자열은 `charAt()`으로 문자 단위 접근이 가능하다.
- `StringBuilder`를 `String`으로 변환할 때는 `toString()`을 사용한다.

<br>

# 실수한 부분

### 1. 문자열 길이가 변할 때 인덱스 값을 빼주지 않음

`for`문의 `i++`와 `i--`가 서로 상쇄되어 같은 위치를 계속 확인할 수 있다.

삭제하지 않은 경우에는 다음 위치로 이동하고, 삭제한 경우에만 이전 위치를 확인해야 한다.

### 2. `i = 0`일 때 인덱스 처리

문자 삭제는 `i = 0`에서도 가능하지만, `i--`는 이전 위치가 존재할 때만 실행해야 한다.

- `deleteCharAt(i)`는 인덱스 0에서도 가능하다.
- `i > 0`인 경우에만 이전 인덱스로 돌아간다.
- `while`문에서는 `i`가 자동으로 증가하지 않으므로 직접 관리해야 한다.

### 3. 숫자를 끝까지 제거하지 못하는 경우

예를 들어 `"98765"`에서 2개를 제거해야 한다면 앞 숫자가 뒤 숫자보다 작은 경우가 없다.

따라서 마지막 숫자부터 제거하여 `"987"`을 만들어야 한다.

### 4. StringBuilder 중간 삭제의 시간복잡도

`deleteCharAt(i)`는 삭제한 위치 뒤의 문자들을 이동시킨다.

따라서 중간 삭제를 반복하면 최악의 경우 `O(N²)`이 발생할 수 있다.

이를 해결하기 위해 `StringBuilder`의 마지막 문자만 제거하는 스택 방식으로 개선한다.
