# SWEA 2112. 보호 필름

## 1️⃣ 문제 접근 방식

#### 📌 사용 알고리즘 - DFS + 백트래킹 + 가지치기

각 행마다 약품을 투입하지 않는 경우, A 약품을 투입하는 경우, B 약품을 투입하는 경우 총 3가지를 DFS로 탐색했음 !

모든 행의 약품 투입 여부를 결정한 후, 모든 열에서 동일한 특성이 K개 이상 연속되는지 검사하여 최소 약품 투입 횟수를 구함

## 2️⃣ 핵심 아이디어

🌟 각 행마다 3가지 선택 가능
- 약품 미투입 → 원본 유지
- A 약품 투입 → 해당 행 전체를 `0`으로 변경
- B 약품 투입 → 해당 행 전체를 `1`로 변경

🌟 `dfs(rowIdx, medicine)`
- `rowIdx` : 현재 탐색 중인 행
- `medicine` : 현재까지 약품을 투입한 횟수
- `minCount` : 최소 약품 투입 횟수

🌟 약품 투입 후 다른 경우의 수를 탐색하기 위해 원본 행을 복구하는 백트래킹 필요

🌟 이미 `medicine >= minCount`라면 최소 횟수를 갱신할 수 없으므로 가지치기

🌟 연속된 K개 행에 동일한 약품을 투입하면 반드시 통과하므로 `minCount = K`로 초기화 가능

---

✏️ 풀이 과정

1. `dfs(0, 0)`부터 시작하여 각 행마다 3가지 경우 탐색
2. 약품을 투입하는 경우 `Arrays.fill()`로 해당 행 전체를 0 또는 1로 변경
3. 다음 행 탐색을 마친 후 원본 배열로 복구
4. `rowIdx == D`가 되면 모든 열에 대해 `checkCols()`로 성능 검사
5. 모든 열이 통과하면 `minCount` 갱신
6. 이미 약품 투입 횟수가 `minCount` 이상이면 탐색 중단

`checkCols()`에서는 현재 특성과 이전 특성이 같으면 `count++`, 다르면 `count = 1`로 초기화

`count >= K`이면 통과하고, 현재 연속 개수와 남은 행을 모두 합쳐도 K개가 될 수 없다면 검사 종료

## 3️⃣ 시간복잡도

`O(3^D × D × W)`

각 행마다 3가지 선택이 있으므로 최대 `3^D`가지 경우의 수 발생

각 경우에서 모든 열을 검사하며, 한 열당 최대 D개 행을 확인하므로 `O(D × W)` !

다만 `medicine >= minCount` 가지치기로 실제 탐색 횟수를 줄일 수 있음

## 4️⃣ 풀이하면서 실수했던 부분

- DFS 종료 조건인 `rowIdx == D`에서 `minCount` 갱신 후 `return`을 누락하여 재귀가 계속 호출되는 문제 발생
- `K == 1`이면 약품 투입 없이 무조건 통과하지만, `checkCols()`에서 첫 번째 셀의 연속 개수를 검사하지 않아 해당 예외 조건을 놓쳤음
- 가지치기를 `medicine > minCount`로 작성했으나, 같아지는 순간부터 더 탐색할 필요가 없으므로 `>=`로 수정
- 원본 행 복구 시 배열 참조에 주의해야 함. 원본을 `clone()`으로 백업하고 A, B 탐색이 모두 끝난 후 복구하도록 수정

## 5️⃣ 다시 푼다면 개선하고 싶은 점

처음부터 약품을 투입하지 않고 성능 검사만 하는 로직을 작성했는데, 문제에서 요구하는 최소 약품 투입 횟수를 구하려면 DFS로 모든 경우를 탐색해야 한다는 점을 먼저 파악했으면 좋았을 듯함

특히 DFS를 구현할 때 종료 조건에서 반드시 `return`하는지 확인하고, `K == 1`처럼 무조건 통과하는 예외 조건과 최소 정답의 상한을 먼저 생각하여 가지치기를 적용하면 더 효율적으로 풀 수 있을 듯함
