# 접근 방법
각 숫자에 포함된 닫힌 영역의 개수를 이용하여 주어진 X를 만들면서 가장 작은 정수를 구성한다.
<br>

# 핵심 아이디어

- X = 1인 경우 가장 작은 음이 아닌 정수는 0이다.
- X가 짝수인 경우 8을 X / 2개 사용한다.
- X가 홀수인 경우 4를 하나 사용하고, 나머지는 8을 사용한다.
- 0은 가장 작은 숫자이지만 여러 자리 수의 앞에 올 수 없기 때문에 X가 1인 경우에만 사용할 수 있다.

<br>

# 시간복잡도
각 테스트 케이스마다 X / 2번 반복하여 8을 추가하므로, `O(X)`


테스트 케이스가 T개라면 전체 시간복잡도는
`O(T × X)`
<br>

# 어려웠던 점
생각보다 풀이가 쉬웠는데 처음 문제를 봤을 때 당연히 어려운 문제일 거라 생각해서 풀이 방법이 생각나지 않았습니다.
