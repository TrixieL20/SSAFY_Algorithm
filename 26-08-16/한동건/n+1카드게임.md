# 접근 방법

문제에서는 뽑은 카드 중 선택한 카드를 제외하고 "버려야"한다고 돼있다.

하지만 선택을 한다는 접근 말고 카드를 keep하는 접근을 시도했다.
라운드마다 뽑은 카드를 현재 카드 배열에 넣은 뒤, n+1이 쌍이 되고, 코인이 부족하지 않다면 사용하고 다음 라운드로 넘어갔다.

<br>

# 핵심 아이디어

어차피 미래에 어떤 카드가 필요한지 지금은 알 수 없으므로, 모든 카드를 버리지 않고 일단 보관해 둔다. 그러다 라운드를 넘기기 위한 카드 쌍이 부족해지는 순간, 마치 과거 해당 카드를 뽑았을 때 코인을 썼던 것처럼 소모하고 카드를 제출한다.

<br>

# 시간복잡도

평균 O(n^2)

canNextRound() 내부 이중 for문 O(N^2)

canNextRound() X 라운드 반복(O(N)) = O(N^3)

<br>

# 어려웠던 점 / 배운점

정답 풀이 로직...은 사실 혼자 생각한건 아니고 도움을 받았다.

처음에 게임의 룰 그대로 뽑은 카드 중 선택하고 나머지를 버린다에서 
선택의 기준을 정하는게 어려웠었다.

"수중에 있는 카드 만으로 판단해서 다음 라운드로 갈 수 있는 카드를 선택해야하나?", "그렇게만 뽑으면 코인은 남아돌지만 이전에 뽑지 않은 카드로 인해 쌍이 안 이루어져서 다음 라운드 못 가는데.." 처럼 혼란스러웠다

앞으로 문제를 유연하게, 쉽게, 다각적으로 풀 수 있도록 생각해야겠다.
