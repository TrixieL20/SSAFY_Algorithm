# 문제 접근 방식
- 미리 n+1이 되는 카드 쌍을 구해놓기
- 코인 소모되는 기준으로 라운드 진행 여부 판

# 핵심 아이디어
- n+1이 되는 카드 쌍들을 각각의 카드를 획득 가능한 시점으로 변환해서 pairs에 저장

# 복잡도
## 시간 복잡도
O(n^2 * logn)
- n + 1 카드 쌍(pairs) 저장: O(n^2)
- 카드 쌍(pairs) 정렬: O(nlogn)
- 라운드 진행 시뮬레이션: O(n^2 * logn)
## 공간 복잡도
O(n)
