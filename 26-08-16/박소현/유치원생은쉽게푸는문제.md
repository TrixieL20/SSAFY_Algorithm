# 문제 접근 방식
- 답으로 나올 수 있는 숫자는 0과 8로 정해져 있다.

# 핵심 아이디어
N이 홀수인지 짝수인지 확인 후, 홀수 일 때는 4를 맨 앞에 추가.

# 복잡도
## 시간 복잡도
O(N/2) => O(N)
## 공간 복잡도
O(N) => sb 출력 길이 총합

# 풀이하면서 실수했던 부분
- N이 홀수일 때는 0이 아니라 4를 맨 앞으로 보내야 했는데, 0을 맨 뒤에 추가하고 있었다.
   => 문제 댓글 보고 알아차릴 수 있었다.
- sb를 사용해서 append하는데, sb를 매 test 케이스마다 초기화해서 print했다.
