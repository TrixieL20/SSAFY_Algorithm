# 접근 방법

문제에서 요구하는 것은 **주어진 자리수 `n`을 만족하면서 가장 작은 수를 만드는 것**이다.

가장 작은 수를 만들기 위해서는 크게 두 가지를 고려해야 한다.

1. **자리수가 작아야 한다.**
2. 같은 자리수라면 **앞쪽에 오는 숫자가 작아야 한다.**

문제에서 사용할 수 있는 숫자는 제한되어 있기 때문에 `n`에 따라 만들 수 있는 가장 작은 수의 규칙을 찾아보았다.

수를 만들기 위해 필요한 성냥개비의 개수를 기준으로 살펴보면 다음과 같은 규칙을 확인할 수 있다.

* `n = 0` → `1`
* `n = 1` → `0`
* `n = 2` → `8`
* `n`이 짝수 → `8`을 `n / 2`개 사용
* `n`이 홀수 → `48`로 시작하고 이후 `8`을 `(n - 3) / 2`개 사용

따라서 별도의 탐색 없이 `n`의 홀짝에 따라 결과를 바로 만들 수 있다.

<br>

# 핵심 아이디어

### 가장 작은 수를 만들려면?

숫자의 크기를 비교할 때 **자리수가 적은 수가 무조건 더 작다.**

따라서 먼저 주어진 자원으로 만들 수 있는 **최소 자리수**를 만들어야 한다.

그리고 같은 자리수라면 **가장 앞에 오는 숫자를 작게 만드는 것**이 중요하다.

이 원칙에 따라 `n`이 짝수인 경우에는 `8` 하나를 만드는 데 필요한 자원을 반복해서 사용하면 가장 작은 수를 만들 수 있다.

```text
n = 2  →  8
n = 4  →  88
n = 6  →  888
...
```

따라서 짝수 `n`에서는 `8`을 `n / 2`개 출력하면 된다.

반면 `n`이 홀수인 경우에는 `8`만으로 정확한 자원을 사용할 수 없기 때문에 가장 앞에 `4`를 배치하고 나머지를 `8`로 채운다.

```text
n = 3  →  48
n = 5  →  488
n = 7  →  4888
...
```

따라서 홀수 `n`에서는 `48`을 먼저 만들고, 남은 자원으로 `8`을 `(n - 3) / 2`개 추가한다.

<br>

# 구현 포인트

`n`이 작은 경우에는 별도로 처리했다.

```java
if (n == 0) → 1
if (n == 1) → 0
if (n == 2) → 8
```

그 이후에는 `n`의 홀짝만 확인하면 된다.

```java
if (n % 2 == 0) {
    // 8을 n / 2개
}

if (n % 2 != 0) {
    // 48 + 8을 (n - 3) / 2개
}
```

문자열을 이용해 결과를 구성했다.

<br>

# 시간복잡도

결과로 출력해야 하는 문자열의 길이만큼 반복문이 수행된다.

최대 `n`에 비례하여 문자열을 생성하므로 시간복잡도는 O(n)이다.

결과 문자열을 저장하기 위한 공간복잡도 역시  O(n)이다.

# 헤멘 부분

처음에는 주어진 `n`에 따라 어떤 숫자를 조합해야 가장 작은 수가 되는지 규칙을 잘못 찾아서 홀수일 때는 0이 들어가야 한다고 생각했고 자릿수가 2이상일 때, 2번째 자리에 4가 올 때 최적이라고 생각했다.

하지만 앞자리가 작은게 제일 좋으므로 앞자리에 올 수 있는 4를 처음 배치하는 것이 n이 홀수일 때 조건을 만족하는 가장 작은 수를 찾을 수 있다는 것을 알 수 있었다.
